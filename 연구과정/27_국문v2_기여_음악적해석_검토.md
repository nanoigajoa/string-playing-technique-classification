# 27 · 국문 v2의 연구 기여·음악적 해석 검토

검토일: 2026-10-05. 대상은 `paper/manuscripts/v2/주법분류_논문초안_국문_v2.md`다. 사용자가 요청한 국문 전체 원고의 내용 검토를 수행하고 본문과 출력본에 수정 사항을 반영했다.

## 1. 검토 판단

현재 원고의 중심 질문과 결과는 연결된다. **이 자료의 제한 라벨·악기종 보류 조건에서, 두 분류 구성의 작은 전체 평균 차이만으로 악기종·주법별 성능을 대표할 수 없다는 비교 관찰**이 가장 분명한 결과다. 자기학습은 같은 질문을 대신하는 중심 기여가 아니라 미라벨 자료 활용의 보조 진단으로 유지한다. 결과 출처와 재계산 자료는 이 관찰을 확인할 수 있게 하는 근거다.

현재 증거는 새로운 분류 방법, 주법의 음향적 원인 발견, 모델 동등성 또는 일반적인 평가 이론을 입증하지 않는다. **내용의 정합성 검토는 완료했지만, 특정 학술지 연구 논문으로 충분한 독립 기여가 확보됐다고 확정하는 판단은 아니다.** 기여의 강도에 관한 아래 평가는 검토자의 판단이며 게재 가능성이나 심사 결과의 예측이 아니다.

## 2. 연구 기여와 실제 증거

| 기여 후보 | 현재 증거 | 검토 판단·본문 처리 |
|---|---|---|
| 제한 라벨에서 특징 SVM과 고정 MERT 헤드 비교 | 표 4: 네 예산의 평균 차이는 절댓값 0.01 미만. 50%의 악기종별 차이는 +0.0213/−0.0468/−0.0218/+0.0146 | 이 부분집합에서 전체 평균과 조건별 결과가 다른 양상을 보인다는 경험적 결과. 보편적인 모델 선택 규칙으로 확대하지 않음 |
| 주법별 성능과 오류 방향 | 50% col legno battuto F1은 MERT/SVM 0.7423/0.8248, sul ponticello는 0.7678/0.7386. 그림 5의 혼동 방향도 확인 | 음악 라벨에 연결되는 결과. 분류기의 내부 사용 단서나 음향적 원인의 증명은 아님 |
| 자기학습의 라벨 예산별 변화 | 표 5: 의사 라벨−감독 평균 −0.0322/+0.0062/+0.0098/+0.0047. 5% 클래스 F1 차이는 모두 음수 | 고정 임계값·헤드·선택 정책의 진단. 일반적인 준지도학습 실패나 유의한 개선으로 표현하지 않음 |
| 재표집 민감도·결과 출처·재계산 | 같은 예측에 대한 12개 차이 구간 모두 0 포함. 기존 checkpoint 대조 기록과 저장 예측 재계산 경로 | 앞의 결과를 추적하는 연구 자료. 구현 오류 수정 자체를 새로운 평가 이론의 발견으로 삼지 않음 |

악기종별 차이는 바이올린·비올라·첼로·콘트라베이스 순서다. 모든 차이는 점추정이며 통계적으로 확정된 집단별 효과로 표현하지 않았다. 위 수치의 출처는 [악기종별 평균](../paper/manuscripts/v2/tables/instrument_means.csv), [클래스별 F1](../paper/manuscripts/v2/tables/per_class_f1.csv), [자기학습 요약](../paper/manuscripts/v2/tables/self_training_summary.csv), [재표집 민감도](../paper/manuscripts/v2/tables/bootstrap_sensitivity.csv)다.

### 직접 선행 연구와 구분되는 범위

현악 특징/SVM 분류는 이미 연구됐으므로 적용 자체를 새 방법으로 볼 수 없다. 현재 구현은 Kruger and Jacobs(2020)의 재현 실험도 아니다. [출판사 기록](https://www.tandfonline.com/doi/abs/10.1080/09298215.2020.1784957)과 로컬 원문을 대조했다.

국문 v2에 빠져 있던 MERTech를 2.2절과 참고문헌에 추가했다. MERT를 주법 인식에 사용하는 선행 사례이며, 고정 표현 probing도 다룬다. 현재의 현악 고립 음·제한 라벨·악기종 보류 비교와 과제 범위를 구별했다. [저자 프리프린트](https://arxiv.org/abs/2310.09853v1), [저자 공식 코드](https://github.com/LiDCC/MERTech)를 확인했다. 본문은 직접 대조한 2023년 arXiv v1을 인용하며, 이를 2024년 게재본 전문을 대조한 것으로 표시하지 않았다.

**이 범위 차이 자체가 분야 최초나 충분한 신규성을 입증하지는 않는다.** 이번 검토는 직접 관련된 문헌의 누락을 보완한 것이며 2026년까지의 모든 연구를 망라한 체계적 문헌 고찰이 아니다.

## 3. 음악적 해석: 관찰과 가설의 구분

| 음악적 구분 | 현재 관찰 | 문헌·정의가 제공하는 설명 | 아직 입증하지 못한 것 |
|---|---|---|---|
| ordinario / sul ponticello | 50%의 sul ponticello→ordinario 비율 MERT/SVM 0.2141/0.2362, 역방향 0.0615/0.0659 | 지속 활긋기에서 접촉 위치가 다른 구분. Su et al.(2014), Ducher and Esling(2019)과 연결 | 비대칭의 원인이 음색·표본 수·특징 손실 중 무엇인지 |
| col legno battuto / pizzicato secco | 50%의 col legno→pizzicato 비율 MERT/SVM 0.1953/0.1116, 역방향 0.1215/0.0991 | 나무 타격과 손가락 뜯기의 다른 가진 방식. 발음·감쇠의 유사성은 가능한 가설 | 본 클립의 청취·음향적 유사성 및 실제 모델 의존성 |
| tremolo | 50% 클래스 F1 MERT/SVM 0.9760/0.9606 | 반복 활긋기의 시간 변동이라는 주법 의미 | 반복성 때문에 높은 성능을 얻었는지, 다른 단서를 사용했는지 |

혼동 비율은 [canonical 합산 혼동행렬](../results/phase1/canonical/verification/confusion_counts.csv)의 실제 클래스 행으로 나눈 값이다. 클래스 F1의 평균과 합산 혼동행렬 재현율을 같은 통계량으로 취급하지 않았다. 세 반복의 10,206개 예측은 고유 음원 3,402개의 반복 예측이다.

음악적 정의와 다차원 분류의 근거는 [Ducher and Esling 원문 §3](https://archives.ismir.net/ismir2019/paper/000086.pdf), 접촉 위치에 관한 음향적 논의는 로컬 Su et al.(2014) 원문의 §II·그림 3 및 초록을 직접 읽었다. [Su의 저자 서지](https://homepage.iis.sinica.edu.tw/pages/lisu/publications_en.html)도 확인했다. 이 문헌의 신호 분석을 본 자료에서 다시 수행한 결과로 옮기지 않았다.

시간 평균의 설명도 수정했다. 분류 헤드에 프레임 순서를 명시적으로 전달하지 않는 것은 사실이지만, 특징에는 시간 차분이 있고 MERT는 문맥화한 표현을 평균한다. 따라서 ‘시간 평균 → 시간 정보 없음 → 특정 주법 오류’의 인과 연결은 성립하지 않는다.

전문 연주자 청취, 지각적 타당성 평가 또는 음향 단서 개입 실험은 이번 검토에서 수행하지 않았다. 음악적 해석의 인과적 타당성이 검증됐다는 판정을 내리지 않는다.

## 4. 추가로 확인한 5% 자기학습 결과

[저장 클래스 F1](../results/phase1/canonical/self_training/per_class_f1.csv)에서 의사 라벨−감독 차이를 직접 계산했다.

| 주법 | F1 차이 |
|---|---:|
| ordinario | −0.0242 |
| pizzicato secco | −0.0502 |
| tremolo | −0.0118 |
| sul ponticello | −0.0381 |
| col legno battuto | −0.0367 |

다섯 클래스 모두 하락했고 가장 큰 하락은 pizzicato secco였다. 따라서 소수 클래스 두 개에만 평균 하락을 귀속하는 설명은 적절하지 않다. 이 결과를 4.4절에 추가했다. 기존 요약·지표는 바뀌지 않았으며, 저장 값의 차이를 상세화한 것이다. 오류 누적이나 class weight 변화가 원인이라는 판단은 하지 않았다.

## 5. 초록·서론·결론의 연결과 수정

- **초록:** 제한 라벨 MERT/SVM 비교 → 조건별 차이 → 자기학습 보조 결과 → 고정 예측 재표집과 적용 범위로 이어져 핵심 질문과 일치했다. 주요 수치를 유지했다.
- **서론:** 기여 세 항목을 관찰 결과 두 개와 재현 자료 한 개로 구체화하고, 결과 절과 연결했다. ‘학습에 없던 악기종’은 주법 분류기 학습에서 보류한 악기종이라는 뜻으로 명확히 했다.
- **관련 연구:** MERTech와 현재 실험의 범위를 구별했다. 모델 효과를 표현 자체의 효과로 분리하지 않는 기존 설명을 유지했다.
- **결과:** 소수 클래스의 빈도로 원인을 단정하는 문장을 관찰과 미분리 요인으로 나눴고, 5% 자기학습의 클래스별 차이를 추가했다.
- **논의:** 문헌·오류 방향·가능한 설명·미확인 원인의 순서로 5.2절을 보완했다. 시간 평균과 시간 정보의 관계를 정확히 설명했다.
- **한계:** 악기종 보류가 다운스트림 분류기 학습의 경계임을 명시했다. MERT 사전학습 자료에 해당·관련 녹음이 포함됐는지는 이번 감사에서 확인하지 않았다. 포함됐다는 주장도 하지 않는다.
- **결론:** 서론과 같은 기여 범위를 사용하고, 오류의 음향적 원인과 새 연주자·세션·실제 연주 적용이 미확인임을 연결했다.

## 6. 검증과 출력본

`python3 src/phase1_paper_v2_export.py`와 `python3 src/phase1_paper_v2_verify.py`를 실행했다. 기존 검증에 5% 클래스 F1 차이의 원자료 대조와 변경 문장의 Markdown/DOCX/HTML/PDF 포함 여부 검사를 추가했다. 수치 표 6개, 그림 입력·출력 해시, DOCX ZIP·표 7개·그림 6개, 참고문헌 11편 및 출력본의 새 내용 대조를 통과했다. 설정 표 3은 기존 코드 대조 범위다.

현재 [PDF](../paper/manuscripts/v2/review_ko_v2.pdf)는 19쪽이다. 19쪽 모두를 렌더링한 축소 페이지 모음으로 배치를 확인하고, 변경한 결과·논의·한계·결론 페이지를 개별 이미지로 확대 확인했다. 그림 여섯 개와 캡션은 각각 같은 페이지에 있으며 표제와 표의 분리·잘림은 발견하지 않았다. Word는 편집 가능한 구조를 검사했으며 Word 앱의 실제 페이지 배치를 확인한 것은 아니다.

[자동 대조 결과](../paper/manuscripts/v2/VERIFICATION.json)와 [산출물 해시](../paper/manuscripts/v2/artifact_manifest.json)를 갱신했다. 이번에는 문장·기여 해석을 검토했으며 새 모델 학습이나 checkpoint 추론, 전체 bootstrap 재실행은 하지 않았다.

## 7. 현재 상태와 다음 단계

국문 v2의 기여·음악적 해석·논리 검토와 본문 수정은 완료했다. 최신 원고와 출력본은 `paper/manuscripts/v2/`를 사용한다. 다음 집필 단계는 이 범위를 유지한 영문 v2 대응본이다.

실제 투고 판단에서는 저자가 위의 경험적 비교 기여를 어떻게 평가할지, 저자·소속·지원·이해상충·AI 도구 사용 선언과 공개 자료의 라이선스·주소를 확정해야 한다. 새로운 연구 기여를 강화하려고 추가 실험을 선택한다면 별도 질문·계획으로 정한다. 이번 내용 검토 완료가 추가 실험의 실행, 자료 공개나 학술지 제출을 의미하지 않는다.
