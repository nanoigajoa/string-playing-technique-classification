## 채택된 수정 방향 (확정 — `연구과정/08_지시_누수수정후속.md` 반영)

- **A → 검증셋 기반 iteration 선택**: 원본 seed 라벨에서 **iteration-선택 전용 val(`val_select`)** 을 떼어(early-stop용 val과 **분리**), 매 iteration 모델을 `val_select`에 평가 → `argmax(val_select_f1)` iteration의 test F1을 보고.
- **B → OrchideaSOL(소스 도메인) val에서 τ 고정** *(후속지시서 권장 2번, 기존 "τ=0.9 사전고정" 대체)*: `best_tau`(Pool B 기반) 삭제. OrchideaSOL 내부 val에서 τ를 미리 결정 → **타깃 도메인 정보 전혀 사용 없이** Philharmonia에 그대로 적용. Pool B는 최종 평가 1회만. 3개 τ는 부록 sensitivity 표.
- **범위**: A/B/C 수정 + **Wilcoxon signed-rank 유의성 검정(1-4, 주 실험 1개·정직한 검정력 한계)** 을 한 번의 재실행 패스로.
- **⚠ 게이트**: 재실행 후 **누수 제거 전후 비교표**를 먼저 생성·보고하고 **거기서 멈춘다**. 비교표로 연구 질문 방향을 확정한 뒤에만 다음 단계(ALM 확장 등)로 간다. 누수 제거 전 숫자로 서사를 확정하지 않는다.

## 수정 상세

### 1. `notebooks/04_phase1.ipynb`

**cell 12 `self_training()`** — **두 종류의 val을 반드시 분리**:

> ⚠ 후속지시서 핵심 주의점: early-stop용 val과 iteration-선택용 val을 같은 것으로 쓰면 그 val에 이중 최적화되어 **또 다른 누수**가 된다. 반드시 분리한다.

```
labeled seed ─┬─ val_select : iteration 선택 전용 (pseudo-labeling·early-stop·test와 완전 분리, 진짜 라벨)
              └─ seed_core  : head 학습 입력 (여기서 다시 early-stop용 val을 뗌 = cell 9 기존 구조)
unlabeled pool → pseudo-labeling 대상 (여기서 val을 떼지 않음)
test           → 최종 1회만
```

- 함수 진입 시 `split['labeled_idx']`(원본 seed, pseudo-label 오염 전)에서 `val_select`를 **1회 분리·고정**. 나머지가 `seed_core`.
- 각 iteration: head는 `seed_core(+ 채택된 pseudo-label)`로 학습(내부 early-stop val은 이 풀에서 별도 분리), **`val_select`(진짜 라벨, 고정)** 와 test 각각 평가 → `val_sel_f1_list`, `test_f1_list` 축적.
- pseudo-labeling 대상 unlabeled pool은 `val_select`를 절대 포함하지 않음.
- 반환에 `val_sel_f1`, `iter_f1`(test) 둘 다 포함.
- **주의(소규모 seed)**: 5% seed는 클래스당 한 자릿수 → 3분할이 과할 수 있음. 데이터가 부족하면 후속지시서 원칙대로 최소한 **`val_select`는 test와 완전 분리**만은 절대 지키고, seed_core 내부 early-stop val과의 분리는 여력 범위에서 유지.

**cell 13/15** — `best_st_f1` 재정의:
```python
best_it = int(np.argmax(result['val_sel_f1'])) if result['val_sel_f1'] else -1
'best_st_f1': result['iter_f1'][best_it] if result['iter_f1'] else base_macro,
'sel_iter':   best_it,   # 투명성: 어느 iteration이 선택됐는지 기록
```
- cell 15는 재현성 위해 `val_sel_f1`/`iter_f1` 배열도 컬럼으로 저장(Wilcoxon·검증용).

**cell 20** — cherry-pick 제거:
- `best_overall`/`best_cond`(단일 fold idxmax) 라인 삭제.
- 헤드라인을 **4-fold 평균±표준편차**로: 예) `- Best config (50%, τ=0.7): F1=mean±std over 4 folds × 3 trials`.

### 2. `src/phase4_crossdomain.py` (`run_train`, 약 line 331/480~583)

**결함 B 수정 범위 사전 파악 결과 (후속지시서 65~67 요구):**

**수정 내용:**
- line 481 `best_tau = df_summary.groupby('tau')['pool_b_f1'].max().idxmax()` **삭제** (Pool B 기반 선택 = 누수).
- **OrchideaSOL 내부 val에서 τ 결정**: OrchideaSOL 임베딩을 train/val로 분리(악기 단위 GroupKFold 또는 stratified holdout, seed 고정) → 각 τ로 self-training(Pool A를 unlabeled로 사용) 후 **OrchideaSOL val**에서 F1 측정 → 최고 τ 선택. 타깃(Philharmonia) 라벨 미사용.
- 선택된 τ를 Pool A→Pool B에 그대로 적용. **Pool B F1은 선택이 아닌 최종 보고용 1회만** 계산.
- τ 3개 결과는 **부록 sensitivity 표**로 유지.
- report.md: "Self-training 최고(τ=0.8)" → "Self-training (τ=X, OrchideaSOL val에서 선택 — 타깃 도메인 정보 미사용)". 논문에 "타깃 도메인 라벨을 전혀 보지 않고 τ를 고정했다"는 방법론적 강점으로 명시. `zero_shot_f1=0.4226` 하드코딩 유지하되 주석 명시.

### 3. NEW `src/phase1_significance.py` (지시서 1-4 + 후속지시서 "검정력 현실")

- `results/phase1/all_results.csv`(수정본) 로드.
- **주 실험 1개만 검정** (후속지시서: 다중비교 보정까지 하면 저검정력에서 아무것도 안 나옴). 사전 지정 primary = **seed 20%, τ=0.7** (또는 비교표 확인 후 확정). 나머지 seed/모델은 기술통계로만 보고.
- **paired 단위 = fold (n=4)**. trial(3회)은 독립 fold가 아니므로 **fold별로 trial 평균을 먼저 낸 뒤** baseline↔self-training 4쌍을 만든다. (fold×trial=12로 n을 부풀리지 않음.)
- `scipy.stats.wilcoxon`(paired, signed-rank) → p-value + 향상폭 mean±std.
- **정직한 검정력 한계 명시**: "fold 4개로는 p<0.05가 수학적으로 거의 나오지 않는다. 향상은 관찰되나 fold 수가 적어 통계적 유의성은 확정할 수 없다"를 리포트에 그대로 기술. 억지 유의성 주장 금지.
- 출력: `results/phase1/significance.md` (primary 실험: n=4 fold별 Δ, Wilcoxon p, 검정력 한계 문구).
- 재사용: `phase1_svm_seed_comparison.py`의 로딩 패턴(`load_mert_results`) 참고.
