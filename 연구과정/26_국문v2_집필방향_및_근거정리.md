# 26 · 국문 v2 집필 방향과 근거 정리

작성: 2026-10-02. 사용자 요청: 기존 국·영문 v0/v1을 바탕으로 방향을 단순화하고, 연구 흐름을 기록한 뒤 국문 v2와 필요한 그림을 먼저 완성한다.

## 현재 원고의 목표

**제한 라벨 조건에서, 학습에 없던 악기종의 현악 주법을 특징 기반 SVM과 고정 MERT 표현 기반 분류기가 얼마나 구분하고 어디에서 혼동하는지 설명한다.**

주요 비교는 MERT/SVM이다. 자기학습은 미라벨 자료 활용의 보조 실험으로, 라벨·검증·저장 예측 감사는 결과의 신뢰성을 뒷받침하는 방법으로 배치한다. 국문 전체 원고 완성 후 영문 대응본을 작성한다.

## 기존 연구에서 이번 집필까지

1. 특징 기반 모델과 CNN에서 시작해 MERT·자기학습·해석·외부 전이로 확장했다.
2. v0는 ‘평가 함정 → 결론 반전 → 모델 동급 → 음향적 기전’의 논증으로 작성됐다.
3. 후속 감사에서 숨은 정답 target 접근, 학습 밖 통계량, checkpoint와 결과 연결, 추론 범위 문제가 확인됐다.
4. canonical 재실행과 검증으로 MERT/SVM·자기학습·CNN의 결과 출처를 정리했고 v1에 반영했다. 저장 예측만으로 표를 다시 계산하는 별도 재현 경로도 확인했다.
5. v1은 검증된 결과를 중심으로 축약되어 v0의 배경과 논의 상당 부분이 빠졌다. v2는 검증된 수치를 유지하면서 전체 논문으로 필요한 설명을 복원한다.

과거 문서의 ‘동급 확정’, ‘결론 반전의 원인 규명’, ‘깊이가 불필요한 기전 입증’은 현재 결론이 아니다. 새 연구자·연주자 자료를 수집하는 장기 계획도 이번 원고의 집필 범위와 구별한다.

## 채택·제외 기준

| 항목 | 결정 |
|---|---|
| v0의 음악적 배경·특징 설명·직접 관련 문헌 | 원문·현재 구현과 대조해 복원 |
| v1의 canonical 수치와 추론 범위 | 본문 근거로 사용 |
| 악기종·주법별 결과 | 기존 저장 예측 및 CSV에서 상세화 |
| 자기학습 | 같은 설정의 감독·의사 라벨·oracle 비교. Oracle은 상한이 아닌 진단 |
| CNN | 전체 라벨의 참고 결과로 부록에 기록 |
| SHAP·층별 probe·LoRA·ALM·외부 전이 | 현재 주요 비교·기전 주장에 연결하지 않음 |
| 결함별 인과 효과·동등성·비용 우위 | 현재 증거가 입증하지 않으므로 주장하지 않음 |

## 원고와 그림 구성

본문: 서론 → 관련 연구 → 데이터와 방법 → 결과 → 논의와 한계 → 결론·재현성.

그림 1은 악기종×주법 표본 분포, 그림 2는 관측 라벨과 학습·검증·테스트 경계, 그림 3은 두 실험의 라벨 예산별 곡선, 그림 4는 악기종별 성능 차이와 주법별 F1, 그림 5는 반복 예측을 합친 행 정규화 혼동행렬, 그림 6은 재표집 단위별 차이 구간을 제시한다. 같은 색·축·클래스 순서를 사용하고, 숫자를 CSV에서 읽어 그린다. 설계도인 그림 2와 수치 그림의 근거를 구별해 기록한다.

본문은 [국문 v2](../paper/manuscripts/v2/주법분류_논문초안_국문_v2.md)에, 그림·표는 `paper/manuscripts/v2/figures/`와 `tables/`에 둔다. 생성 코드와 입력·출력 해시, 원문 대조 기록, 최종 검토 기록을 함께 남긴다.
