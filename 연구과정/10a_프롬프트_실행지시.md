계획이고, 방향 재논의는 필요 없어 — 실행만 하면 돼.

역할: 너는 이 프로젝트의 지도교수 겸 실행자야. Track A(자기모순·사실오류 수정)
→ Track B(등뼈 강화 실험) 순서로 진행하고, Track C(문헌·포지셔닝)는 지금
바로 병행 가능해 (PDF 12편 전편 도착 완료).

진행 규칙:

1. Track A(A1~A7)를 먼저 전부 끝내. 특히 A1(감사 코드의 early-stop val /
   config-선택 val 분리 후 재실행)이 최우선이야. 재실행으로 핵심 수치
   (mert_tuning_audit.md)가 바뀔 수 있어 — 바뀌면 바뀐 대로 정직하게 반영하고,
   "SVM ≈ MERT 동급" 결론이 흔들리는 수준이면 거기서 멈추고 나에게 보고해.
   결론에 유리하게 수치를 고르는 순간 이 논문의 존재 이유가 사라져.

2. A7(사실오류 일괄 수정)은 문서 작업이지만 A1 못지않게 중요해. 특히
   "linear probe 관행이 SSL을 과소평가한다"는 서술은 사실과 달라 (MARBLE의
   probe는 MLP hidden 512). 10번 문서 2.3절의 교정된 서술로 전 문서를 바꿔.
   Kruger 관련 수치·프레임도 원문 대조 결과대로 고쳐 (0.915는 Su의 점수지
   Kruger 것이 아니야. Kruger는 0.938~0.941).

3. 수정할 때 새 누수를 만들지 마. 연구과정/08_지시_누수수정후속.md 의
   주의사항과 docs/method_leakage_note.md 5장 체크리스트를 매 작업마다
   스스로에게 적용해. 시드는 기존 컨벤션(42) 유지하고, 재실행 결과는
   전/후 비교표로 남겨.

4. Track C는 A와 병행해서 지금 시작해도 돼 (문서 작업이라 코드와 충돌 없음).
   C1(포지셔닝 문서)이 B3(LoRA)의 필요 규모를 결정하니까, 큰 실험 전에
   끝내는 게 이득이야. C1.5(20편 평가관행 코딩 표 = 논문 Table 1 후보)는
   재료가 이미 논문/05 의 리뷰 .md 에 다 있어서 반나절이면 돼.
   헤드라인은 "동등 예산 비교 0편"이야 — "튜닝 예산 공개 0편"이라고 쓰면
   틀려 (Kruger·Wang이 그리드를 공개했어).

5. Track A가 끝나면 결과 요약을 보고하고 Track B로 넘어가.
   B1(13층 임베딩 캐시)이 선행이고 이제 선택이 아니라 필수야 — 우리가
   last_hidden_state만 쓴 게 관행(레이어 가중 결합) 이하라서, B1→B2가
   함정③ 방어의 전제야. 그다음 B7은 병렬 가능, 이어서 B4 → B6 → B3.
   B5(FreeMatch)는 삭제됐어 — 하게 되더라도 "EMA 기반 adaptive τ
   (FreeMatch 착안)"로 명명하고 부록 한정이야.

6. Phase 2 분리(C3)는 문서·결과의 "이동"이지 삭제가 아니야.
   results/phase2 와 관련 코드는 보존하고, 본 논문 서사 문서들
   (docs/09_summary.md, README 등)에서만 빼서 별도 LBD 초안 문서로 옮겨.

7. 각 작업 완료 시마다: 무엇을 바꿨고, 수치가 어떻게 변했고, 문서 어디를

   낡은 항목부터 고쳐 (실제로는 32편 리뷰 완료).
