# 28 · 기존 논문 대조에 따른 현재 원고의 기여와 투고처 판정

판정일: 2026-10-07. 대상: 10월 5일 내용 검토를 반영한 [국문 v2](../paper/manuscripts/v2/주법분류_논문초안_국문_v2.md). 현재 비교 결과가 어느 저널의 연구 기여에 맞는지 판단해 달라는 사용자 요청에 따른 검토다.

> 25번 계획과의 구분: 아래의 공통 분류기 대조는 이 검토에서 제안한 선택적 보강안이다. 25번의 네 필수 검증은 현재 원고에 채택한 canonical 결과에 대해 완료한 기록이 있으며, 새 대조 실험을 그 미완료 항목이나 확정된 다음 작업으로 제시하지 않는다. 기여 충분성에 대한 아래의 판단과, 이미 완료한 검증의 상태를 구별한다.

## 1. 결론과 권고

**현재 자료를 중심으로 제출할 1순위는 멀티미디어학회논문지(Journal of Korea Multimedia Society)로 판단한다.** 제한 라벨·악기종 보류 조건에서 두 분류 구성을 비교하고 클래스별 오류를 설명하는 좁은 응용·평가 논문으로는 투고를 시도할 연구 단위가 성립한다. 국문 v2를 해당 형식에 맞추고 관련 연구와 반복별 변동을 더 명확히 하는 편집을 권한다. 새로운 대형 모델이나 독립 음원 수집을 국내 투고의 필수 조건으로 추가하지 않는다.

**해외 1순위 후보는 Machine Learning with Applications(MLWA)다.** 현재의 기여 유형과 직접 연결되는 게재 선례가 있다. 그러나 지금 원고를 그대로 번역해 제출하는 것보다는, 아래의 공통 분류기 대조를 추가해 표현과 헤드가 함께 바뀌는 비교의 해석을 보강하는 경로를 권한다. 이 보강을 완료하면 무조건 충분하다는 뜻은 아니다.

**TISMIR와 Journal of New Music Research(JNMR)는 현재 원고 그대로의 1차 투고처로 권하지 않는다.** TISMIR에서는 재사용 가능한 방법론적 또는 더 넓은 경험적 발견이, JNMR에서는 음악적으로 해석 가능한 새 발견이 현재 증거보다 더 분명해야 한다는 것이 이번 판단이다. 따라서 9월 20일 문서의 ‘TISMIR 고정’ 전략을 현재 v2에 자동 적용하지 않는다.

여기서 ‘투고 가능’은 기여와 범위에 대한 검토자의 판단이며, 편집부의 판정·게재 보장·게재 확률이 아니다. 아래 게재 선례는 저널이 허용하는 연구 유형의 증거다. 일부 과거 논문의 약한 평가 설계나 오래된 게재 사례가 오늘의 심사 기준을 대신하지는 않는다.

## 2. 판단 기준과 확인 범위

다음 네 질문을 사용했다.

1. 비교하는 기술이나 과제 자체가 이미 선행 연구에 있는가?
2. 현재 실험이 선행 연구와 다른 조건에서 무엇을 새로 관찰하는가?
3. 관찰한 차이를 해석할 대조·분할·자료가 충분한가?
4. 그 관찰이 해당 저널의 독자에게 어떤 연구·모델 선택을 돕는가?

원문과 확인 범위를 구별했다. 로컬 PDF는 초록뿐 아니라 관련 방법·평가·결론을 읽었다. 온라인 자료는 출판사 본문·저자 원문·공식 초록 또는 저자 소속기관 서지를 사용했다. 접근하지 못한 전문은 읽었다고 표시하지 않았다. 2026년까지의 모든 논문을 망라한 체계적 고찰은 아니다.

## 4. 현재의 기여는 어디까지 충분한가?

### 성립하는 기여

현재는 공개 음원 부분집합의 고정된 제한 라벨 정책에서, 서로 다른 두 분류 구성의 성능·오류를 추적할 수 있는 경험적 비교다. 악기종 보류, 학습·선택 라벨 예산의 명시, 클래스별 결과, checkpoint–예측–표 연결은 비교 결과를 신뢰하고 재사용하는 데 도움이 된다. 새 분류 알고리즘이 없다는 사실만으로 이 연구 단위가 사라지지는 않는다.

특히 전체 평균과 악기종·주법별 상대 성능의 차이는 관심 클래스에 따라 모델 평가를 달리 읽어야 하는 근거가 된다. 현재 논문의 독자는 ‘어떤 음악 파운데이션 모델이 일반적으로 최고인가’를 결정하는 사람이 아니라 이와 같은 고립 음·제한 라벨 조건의 분류 구성을 검토하는 연구자다.

### 해외 전문저널을 겨냥할 때 부족한 증거

1. **표현과 분류기를 함께 바꾼 비교다.** MERT+선택 헤드와 특징+RBF SVM의 차이는 두 구성의 차이이며, 사전학습 표현만의 효과로 해석할 수 없다. 원고는 이 점을 정직하게 쓰지만, 왜 클래스별 상대 강점이 달라지는지를 좁힐 대조는 없다.
2. **전체 평균의 작은 차이를 안정적인 선택 규칙으로 만들 수 없다.** 저장 결과에서 5% 비올라의 세 반복 F1 범위는 MERT 0.5087–0.7726, SVM 0.3860–0.7714다. 이는 해당 조건의 반복 간 변동이며 새로운 악기 개체의 분포나 신뢰구간이 아니다. 평균 차이 +0.0042만으로 저라벨 MERT 우위를 강조하는 것은 부적절하다.
3. **음악적 원인의 확인이 없다.** 혼동 방향은 유용한 관찰이지만 연주 방식·음향 단서·표본 수 중 무엇이 원인인지 분리하지 않았다.
4. **특정 자기학습 절차의 진단이다.** 단일 고정 임계값과 헤드에서의 변화는 결과지만, 준지도학습의 일반적 효과를 설명하는 발견은 아니다.
5. **새로운 독립 확인 자료가 없다.** 기존 탐색 자료의 재실행과 네 악기종 보류를 새 연주자·세션 평가로 확대할 수 없다. 다만 독립 자료 추가가 모든 저널의 의무라는 뜻은 아니다.

따라서 국내의 좁은 비교·응용 논문으로는 연구 기여가 성립한다는 판단과, TISMIR 수준의 넓은 방법론적 결론에는 증거가 부족하다는 판단은 동시에 가능하다. 유의한 우승 모델이나 새 신경망을 반드시 만들어야 한다는 기준을 적용한 것은 아니다.

MLWA 공식 scope 페이지는 접근 제한으로 직접 확인하지 못했다. 해당 후보의 판단은 실제 게재 논문의 확인된 연구 단위에 근거하며 공식 정책이 새 백본을 요구하거나 요구하지 않는다고 단정하지 않았다.

### 국내 후보의 근거가 어디까지 강한가?

- [정명범·고일주(2007)의 음악 장르 분류](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART001085334)는 음악 신호처리의 주제 적합성을 보여준다. 공식 초록은 클라이맥스 구간 선택을 기존 방식과 비교한다. 2007년 사례만으로 2026년의 기여 충분성을 보장하지 않는다.
- 임좌상·김진만(2014)의 기계학습 실증 비교는 [저자 소속기관 업적](https://dis.smu.ac.kr/kor/edu/Profile.do?empNo=10127357&mode=view&pager.offset=0&pagerLimit=20)과 [공식 권호 목록](https://www.kci.go.kr/kciportal/po/search/poSereArtiList.kci?sereId=000883&volIsseId=VOL000053247)에서 게재 기록을 확인했다. 전문을 직접 대조하지 못했으므로 개별 분할·통계 검정의 질은 평가하지 않았다.
- 김민지 외(2022)의 아리랑 5호 수계 분할 모델 비교는 [저자 연구실 업적](https://vb.pusan.ac.kr/visbic/27580/subview.do)에서 게재처·제목·쪽수를 확인했다. 비교 연구 유형의 최근 상대적 선례이며 오디오 분류의 직접 선례는 아니다. 전문을 직접 읽은 근거로 표시하지 않는다.

이 국내 추천은 공식 분야·확인된 연구 유형과 현재의 검증된 비교를 함께 고려한 판단이다. 같은 저널의 최근 현악 주법 연구 여러 편을 전문까지 대조한 결정은 아니므로 해외 직접 선행 대조보다 국내 기여 합격선에 관한 근거는 제한적이다. 그 한계를 포함해도 현재 원고를 넓은 평가 이론 논문으로 해외에 제출하는 것보다 좁은 국문 비교 논문으로 준비하는 편이 적합하다고 판단한다.

한국음향학회지의 [MRNet 2025](https://www.jask.or.kr/articles/article/0qPE/)는 음악 표현·분류의 주제 적합성을 보여주지만 새 다중 경로 구조와 여러 자료의 결과를 제시한다. 한국컴퓨터정보학회논문지의 [음악 감정 분석 시스템 2025](https://journal.kci.go.kr/jksci/archive/articleView?artiId=ART003228283)는 시스템 구현의 선례다. 두 공식 초록을 확인했으나 이 사실만으로 지금 비교 원고에 필수적인 시스템이나 새 구조를 추가하지 않는다. 이번 최종 1순위도 두 저널로 바꾸지 않는다.

Scientific Reports는 [공식 심사 정책](https://www.nature.com/srep/journal-policies/peer-review)에서 범위·기술적 타당성·과학적 유효성을 기준으로 명시한다. 따라서 ‘새 방법이 없으니 정책상 제출 불가’라고 판단하지 않는다. 다만 현재의 좁은 비교를 어느 독자의 어떤 문제에 연결할지가 약해, 이번 권고에서 우선 후보로 두지 않는다. 외부 평가나 새 모델이 공식적인 일률적 필수 요건이라고 주장하지 않는다.

## 6. 국내 제출 준비와 해외 보강을 구별하기

### 현재 결과로 국내 제출본을 준비할 때

원고의 질문은 현재 제목처럼 제한 라벨·악기종 보류에서 두 분류 구성의 성능과 오류에 둔다. 특징과 표현만의 우열, 모델 동등성, 평가 함정의 새 이론, 실제 교육·연주 효과는 추가하지 않는다.

현재 평균 곡선 옆에 기존 저장 CSV에서 계산한 반복별 점수나 최솟값–최댓값을 보조 표로 제시하면 작은 예산에서의 변동이 명확해진다. 세 반복을 독립 테스트 집단으로 바꿔 검정하지 않는다. 자기학습은 보조 결과로 유지하고, CNN의 전체 라벨 결과는 직접 순위 비교에 넣지 않는다.

선행 연구 표에는 자료·클래스·평가 그룹·라벨 정책·확인한 결과의 차이를 적는다. 새 백본 개발이나 장시간 추가 학습 없이도 가능한 편집이다. 코드·분할·저장 예측의 접근 방법과 저자 선언, 학회 양식은 별도로 마무리한다. 현재 19쪽 검토 PDF의 쪽수를 해당 학회 최종 양식의 분량으로 간주하지 않는다.

### 해외를 목표로 추가할 최소 대조

가장 먼저 권하는 것은 **MERT 표현에도 특징 모델과 같은 RBF SVM을 적용하는 공통 분류기 대조**다. 현재의 특징+SVM을 유지하고, MERT+SVM 한 조건을 같은 48개 분할에 추가한다.

| 항목 | 제안 명세 |
|---|---|
| 줄일 불확실성 | 현재 두 구성의 차이가 헤드 변경에 얼마나 민감한가? 같은 SVM에서도 관찰한 클래스별 상대 강점이 유지되는가? |
| 입력·추가 조건 | 기존 768차원 고정 MERT 벡터 + StandardScaler + RBF SVM. 새 인코더 추출·미세조정은 필요 없음 |
| 분할·예산 | 기존 4개 악기종 보류 × 4개 라벨 예산 × 3회 표집. 동일 직접 학습·설정 선택 index |
| 학습·탐색 | StandardScaler·class weight는 직접 학습 표본에서만 적합. 기존 SVM과 같은 C·γ의 12설정 및 같은 검증 선택 규칙 |
| 주요 결과 | 악기종 평균 macro F1과 대응 차이. 클래스별 F1·혼동은 사전에 정한 보조 분석 |
| 선택 규칙 | 테스트 결과로 C·γ·표현 조건을 선택하지 않음. 저장 모델·예측·manifest를 기존 방식으로 연결 |
| 해석 기준 | 결과가 기존 비교와 달라지면 헤드에 민감한 구성 비교로 결론을 제한. 유지되면 같은 SVM에서의 입력 구성 차이라는 추가 근거로 보고 |
| 성과·중단 기준 | 성능 상승이나 p값을 성공 조건으로 정하지 않음. 비교 조건과 결과 출처를 검증하고 관찰 결과를 모두 보고. 기존 분할·입력 정렬을 복원할 수 없으면 실행하지 않고 먼저 자료 연결을 해결 |

이 실험은 사전학습 자료의 효과·표현의 모든 특성·음향 원인을 분리하지 않는다. 다만 현재 가장 직접적인 해석상의 빈틈 하나를 줄인다. 계산 시간을 실측하지 않아 예상 소요 시간을 단정하지 않는다. 이번 요청에서는 실제 학습을 실행하지 않았다.

두 표현에 SVM과 MLP를 모두 적용하는 2×2 대조는 더 넓은 선택지지만 최소 첫 단계로 강제하지 않는다. 새 독립 자료, 잡음·잔향 개입, 연주자 청취도 중심 주장을 바꿔 강화하려는 경우에 선택한다. 모델 수·실험 수만 늘리는 보강은 권하지 않는다.

## 7. 이전 전략과 다음 작업에 미치는 영향

9월의 TISMIR 우선 전략은 평가 감사의 일반적 교훈을 중심으로 한 원고를 전제로 했다. 현재 v2는 인과 효과·동등성·기전 확정 주장을 철회하고 특정 조건의 구성 비교로 정리됐다. 이번 판단은 그 최종 범위와 실제 게재 선례를 대조한 후속 결정이다.

**현재 원고를 먼저 논문화하는 주 경로는 멀티미디어학회논문지의 국문 비교·평가 원고 준비로 변경한다.** 따라서 영문 번역을 무조건 다음 작업으로 할 필요는 없다. 해외 논문을 우선하려는 선택에서는 MLWA에 맞춘 공통 분류기 대조를 보강한 뒤 영문 v2를 준비하는 경로를 별도로 둔다.

검토 기록과 원고의 기존 결과는 보존했다. 이번에 수치나 원고 본문을 새 투고 주장으로 고쳐 쓰거나 외부 제출하지 않았다.

## 8. 수치 확인과 재검토 가능한 근거

[수치 맥락 JSON](../results/phase1/canonical/verification/venue_review_context_20261007.json)에 원고·입력 CSV의 SHA-256과 저장 실행 48행에서 구한 16개 악기종–예산 조합의 반복 범위를 기록했다. 네 예산의 대응 평균 차이가 기존 요약과 1e-12 이내에서 일치하고, 같은 저장 예측의 12개 차이 구간이 모두 0을 포함함을 확인했다.

이번에는 새 학습·checkpoint 추론·새 유의성 검정·독립 테스트 자료 추가를 수행하지 않았다. 이 숫자 대조는 편집적 기여 판단을 자동으로 증명하는 검증이 아니다. 문헌 확인 한계와 저널별 판단의 근거는 위 표를 따른다.

## 9. 최근 국내 게재 사례 보완 — 2026-10-07

사용자 지적에 따라 2007년 음악 장르 분류 논문을 현재 투고 적합성의 주된 사례로 사용하지 않도록 정정했다. 위의 역사적 서지는 유지하되, 선생님께 보내는 메일에서는 해당 사례를 최근 인접 사례로 교체했다.

[이명호·신주현(2024), 「점진적 전이학습을 활용한 음성 데이터 적응 감정 인식 모델」](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART003114792)은 멀티미디어학회논문지 27(8), 1004–1013에 게재됐다(DOI: 10.9717/kmms.2024.27.8.1004). 공식 서지와 초록을 확인했다. 음성 감정 인식에서 점진적 전이학습을 음성 단독 학습 및 일반 전이학습과 비교하는 연구다. 전문 전체와 분할·통계 검정의 적절성은 이번에 확인하지 않았다.

이 사례는 오디오 AI·전이학습·비교 평가라는 현재 기술 분야의 적합성을 보완한다. 현악 주법 분류나 제한 라벨·악기종 보류와 동일한 평가를 다룬 직접 선례는 아니다. 최근의 같은 과제에 대한 충분한 게재 선례를 확보했다고 주장하지 않으며, 분야 적합성만으로 현재 기여의 게재 충분성이 입증됐다고 판단하지 않는다.
