# 후속 연구 데이터 확보 가능성 확인

확인일: 2026-09-08. 기준 연구는 `23_음악AI_연구방향_및_투고가능성.md`의 B 경로다. 공식 배포 페이지·문서 조사와 로컬 파일 검사를 수행했다. 외부 연락·접근 신청·참여자 모집은 실행하지 않았다. 대용량 신규 오디오는 다운로드하지 않았으며, TU-Note 공식 안내 PDF 약 211KB만 받아 확인했다.

**판단: 기존 자료로 준비 실험은 바로 시작할 수 있다. 공개 데이터만으로 네 악기종·다섯 주법·새 연주자·반복 세션을 모두 충족하는 확인용 데이터는 이번 조사에서 찾지 못했다. 새 녹음의 실제 확보 가능성은 참여 경로와 공간·장비에 대한 사용자 확인이 남아 있다.** 공개 자료가 전혀 없다는 뜻은 아니다. 확보 가능 여부와 연구 질문에 적합한지를 구분한다.

**필요한 데이터 조건**

| 조건 | 판정 기준 |
|---|---|
| 실제 연주 | 합성음·같은 샘플의 재렌더링으로 새 연주자를 대신하지 않음 |
| 주법 | ordinario, pizzicato secco, bow tremolo, sul ponticello, col legno battuto의 정의와 실제 coverage 확인 |
| 그룹 정보 | 익명 performer ID, session ID, instrument type 및 가능하면 physical instrument ID |
| 조건 비교 | 같은 연주자·음고·강약의 주법 대조, 원음과 허용 변형의 연결 ID |
| 독립 확인 | pilot/development와 다른 연주자; 같은 연주자의 모든 세션·take·변형은 같은 partition |
| 사용 범위 | 연구 분석, 음향 변형, 전문가 청취, 논문 예시 공개, 원음 재배포를 구분해서 확인 |

기존 계획의 12명은 제안 규모다. 확보된 인원이나 통계적 검정력 보장이 아니다. 악기종 LOSO와 새 연주자 평가도 서로 다른 질문이다.

**1. 보유 데이터: 원음 존재와 분포를 직접 확인**

재현 명령:

```bash
python3 -B src/phase5_data_feasibility.py
```

산출물은 `results/phase5/data_feasibility/`의 `local_inventory.json`, `local_audio_manifest.csv`, `class_coverage.csv`다. 스크립트는 학습·특징 추출 없이 파일 존재, SHA-256, 파일명 기반 라벨과 metadata를 검사한다. 원음 decoding·청취 품질·음향 fingerprint 유사도 검사는 하지 않았다.

| 자료 | 로컬 확인 | 이번 연구에서 가능한 역할 | 부족한 조건 |
|---|---|---|---|
| OrchideaSOL | 기존 3,402개 metadata 행의 원음 모두 존재 | source 학습, 음악 전문가 검토용 예제 선정, 변형 pilot | 검사한 metadata에 실제 연주자·세션 ID 없음; 기존 데이터 |
| Philharmonia | Strings 전체 MP3 4,477개, 대상 네 악기·다섯 라벨 3,349개 모두 존재 | 기존 도메인 이동 개발·스트레스 분석 | rare class 불균형, 연주자·세션 ID 없음; 기존 Pool B는 새 확인 test가 아님 |
| ErhuPT | WAV 경로 2,523개, 고유 파일 바이트 hash 1,253개 | 얼후의 별도 주법 과제 후보 | 4/7/11-class 폴더의 중복; 현재 서양 현악 5분류와 직접 호환되지 않음 |
| QUARTET 폴더 | 원음 0개, 안내문·요청 초안만 존재 | 아직 데이터 자산으로 셀 수 없음 | 실제 접근 승인 상태를 계정에서 확인하지 않았음 |

OrchideaSOL의 `recording_id` 567개는 악기·음고·강약의 proxy다. 543개 key에 여러 주법이 있지만 실제 session ID가 아니다. 존재하는 원음을 기준으로 ord/tremolo 공통 key는 악기별 120–147개, ord/ponticello는 37–46개다. 따라서 준비용 20쌍을 고를 **파일과 metadata상의 여유는 충분하다.** 동일 연주자임이나 음악적 타당성까지 검증한 결과는 아니다.

Philharmonia의 실제 매핑 수(ordinario cap 적용 전):

| 악기 | ordinario | pizzicato | tremolo | sul ponticello | col legno battuto |
|---|---:|---:|---:|---:|---:|
| Violin | 852 | 49 | 42 | 39 | 44 |
| Viola | 709 | 39 | 6 | 1 | 1 |
| Cello | 747 | 2 | 6 | 1 | 18 |
| Double bass | 764 | 15 | 3 | 1 | 10 |

합계 3,349개 중 ordinario가 3,072개다. 기존 임베딩 577개는 ordinario를 300개로 제한한 결과이고 Pool A/B는 403/174개다. 따라서 미사용 파일이 많다는 사실로 희귀 주법 또는 독립 연주자를 추가 확보했다고 볼 수 없다. Pool B의 ponticello 13개는 모두 violin이다.

추가 발견: 첼로 `cello_Ds5_05_forte_arco-normal.mp3`와 비올라 `viola_G6_05_fortissimo_arco-normal.mp3`가 9,611바이트의 동일 파일이다. 둘 다 기존 Pool A/B에는 없다. 파일명만으로 다른 악기·관측이라고 판단하면 안 된다. 원인은 아직 확인하지 않았고, 중복 파일을 삭제하지 않았다. Erhu도 경로 수를 독립 샘플 수로 보고하면 안 된다. 고유 바이트 수조차 독립 연주자 수를 의미하지 않는다.

**2. 공개·신청형 후보: 실제 확인 결과**

| 후보 | 현재 접근 근거 | 적합성 판단 | 다음 행동 |
|---|---|---|---|
| **TU-Note Violin** | 공식 페이지에 1.49GB ZIP과 PDF; PDF 다운로드 성공 | 실제 두 마이크 비교의 보조 후보. 한 연주자로 소개되며 다섯 주법 corpus는 아님 | 이용 조건 확인 후 작은 paired subset으로 파일 대응·정렬 확인 |
| **Violin Technique Dataset** | Zenodo 설명에 audio + note/technique CSV; 파일은 restricted | 이름과 주석 목적은 가깝지만 공개 설명만으로 우리 라벨·인원·세션 확인 불가 | 전체 다운로드보다 label vocabulary와 group별 count table을 먼저 문의 |
| **mdw cello 연구 자료** | 공식 연구 종료 보고서에 전문 첼리스트의 확장 주법 sound/motion 실험; 담당 연구자 연락처 확인 | 음악적 개입 질문과 가까운 협력 후보. 공개 dataset·공유 승인은 미확인 | 원음·익명 player/session metadata 공유 가능성 문의 후보 |
| **MOSA** | Zenodo restricted, GitHub에 sample과 상세 구조 | violin performer ID 15명 확인; articulation은 legato/staccato, 현재 5라벨 부족 | 연구 질문을 바꿀 때만 재주석 feasibility 검토 |
| **RWC-I** | AIST에 네 현악종 및 각 variation 1–3 목록 | 독립 sample library 후보지만 variation을 연주자 ID로 단정 불가; 5라벨·세션 미확인 | 기관 보유 여부와 현재 배포 경로부터 확인 |
| **QUARTET** | Zenodo restricted; 실제 마이크별 audio 설명 | 녹음 채널 비교 가능성은 있으나 5라벨·독립 연주자 cohort 확인 불가 | 지금 우선 신청할 자료는 아님 |
| **TELMI** | 공식 목록에 Teacher 1–4, contact point·pizzicato 등 연습 | 음악적 단서 검토에 가까우나 클릭한 RepoVizz 파일 경로 접근 실패 | 관리팀에 audio subset·group metadata 생존 여부 문의 후보 |
| **Bach Violin** | Zenodo Open, 265.6MB ZIP; 17명·6.5시간 공식 설명 | 실제 연주자 다양성은 있음. 주법 5종 정답·matched 녹음 조건은 없음 | 현재 확인 corpus로 대체하지 않음 |
| **URMP** | 공식 44곡 안내와 전체 12.5GB 신청 링크 | 악기별 audio와 pitch/note 주석; 현재 5주법 정답 아님 | 음원분리·전사 목적이 생길 때 검토 |
| **MOSA-VPT / VioPTT** | 저자 페이지에 배포 링크; 연결 Zenodo 파일은 이번 도구에서 확인 실패 | 76h 합성, détaché/flageolet/spiccato/pizzicato; 외부 실연주 cohort 아님 | 주법 어휘와 합성 평가를 바꾸지 않는 한 제외 |
| **CSV-TD / VIOLET** | 공식 GitHub에 dataset license 작업 중·coming soon 명시 | 12기법 합성, ponticello/battuto 없음 | 현재 확보 가능한 데이터로 계상하지 않음 |

위 후보의 근거와 사용상 구분:

- TU-Note의 공식 안내는 336 single sounds, 344 two-note sequences, 12 solo 항목과 DPA/BuK WAV 구조를 설명한다. 한 전문 연주자를 이틀에 걸쳐 무향실에서 녹음했고 96kHz/24bit다. 이는 같은 항목의 마이크 간 대응을 점검할 근거지만 두 날짜가 모든 조건에 교차됐다는 증거는 아니다. PDF에서 현재 다섯 라벨이나 명시적 이용 라이선스는 확인하지 못했다. 실제 ZIP 전송·파일 정렬도 미검증이다. [공식 배포](https://depositonce.tu-berlin.de/items/f81ba73c-4d9b-48de-9fbc-31cb03d5b9bc), [공식 package insert](https://depositonce.tu-berlin.de/bitstreams/4a86fb10-cc11-48d2-9884-2f215e6c1679/download).
- Violin Technique Dataset의 설명은 교육용 repertoire와 MusicXML alignment에서 추출한 technique annotation을 말한다. 실제 `metadata.csv`와 어휘는 접근 제한으로 열지 못했다. ‘우리 5종이 있다’거나 ‘수작업 청취 정답’으로 해석하지 않는다. [Zenodo 13773807](https://zenodo.org/records/13773807).
- mdw 프로젝트는 일반·확장 주법의 전문 첼리스트 음향·모션·지각 분석을 수행했다고 공식 종료 보고서에 명시한다. 이것은 데이터 공유 완료의 근거가 아니다. 특히 보고서의 col legno **tratto**를 우리 **battuto**와 섞지 않는다. [FWF 프로젝트](https://www.fwf.ac.at/en/research-radar/10.55776/T1295), [담당 연구자 공식 페이지](https://iwk.mdw.ac.at/pamies-vila/).
- MOSA의 violin ID는 영국 `ev01–ev05`, 대만 `yv01–yv10`이며 1–3 trials다. trial은 별도 recording session으로 자동 해석하지 않는다. 기관/연주자 집단이 얽혀 있어 장소 효과를 분리하기도 어렵다. [metadata 구조](https://github.com/yufenhuang/MOSA-Music-mOtion-and-Semantic-Annotation-dataset/blob/main/MOSA-dataset/dataset.md), [주석과 용도 설명](https://github.com/yufenhuang/MOSA-Music-mOtion-and-Semantic-Annotation-dataset), [신청 페이지](https://zenodo.org/records/11393449).
- RWC의 2026 공개 재배포 논문은 RWC-I를 범위에서 제외한다. 옛 주문 페이지는 스스로 archive임을 명시하므로 과거의 팩스·배포비 경로가 현재 작동한다고 단정하지 않는다. [AIST 안내](https://staff.aist.go.jp/m.goto/RWC-MDB/), [악기 목록](https://staff.aist.go.jp/m.goto/RWC-MDB/rwc-mdb-i.html), [2026 원문, p.2](https://staff.aist.go.jp/m.goto/PAPER/TISMIR202602balke.pdf).
- QUARTET는 내부 비상업 이용과 재배포·공개 전달·변형 제한을 명시한다. 음향 개입용 데이터로 채택하려면 허용 범위를 먼저 해결해야 한다. [공식 조건](https://zenodo.org/records/4774190).
- TELMI의 목록 페이지는 살아 있지만 시도한 Teacher 1 pizzicato 링크의 파일 내용을 얻지 못했다. 페이지 존재와 파일 다운로드 가능을 구분한다. [공식 목록·조건](https://telmi.upf.edu/opendatabase/).
- Bach Violin과 URMP에는 기록된 연주와 관련 주석이 있으나, 그 사실만으로 5주법 평가 가능성을 얻지 못한다. URMP 전체 다운로드는 신청 폼으로 연결되며 이번 도구에서는 폼 내용을 열지 못했다. [Bach Violin](https://zenodo.org/records/6050245), [URMP](https://labsites.rochester.edu/air/projects/URMP.html).
- MOSA-VPT는 저자 페이지의 네 합성 주법 설명까지만 확인했다. CSV-TD는 공식 README가 라이선스 협의 중이라고 명시한다. 둘 다 새 연주자 평가의 대체가 아니다. [VioPTT](https://y10ab1.github.io/VioPTT/), [VIOLET](https://github.com/User-tian/VIOLET).
- ErhuPT의 공식 배포는 Open이며 221.8MB ZIP을 제공한다. 현재 로컬 11-class train/test는 각각 927/326 경로이고 전체 폴더 구조에 재분류 중복이 존재한다. 여러 전문 연주자라는 설명이 있어도 파일별 ID가 확보되지 않으면 player split을 보장할 수 없다. [ErhuPT](https://zenodo.org/records/4320991).

**3. 기존 수집 문서에서 바로잡아야 할 판단**

`자료/데이터셋_마스터.md`의 일부 채택/제외는 현악 음원분리 연구 기준이다. 이번 주법·신뢰성 연구에 그대로 적용하지 않았다. 기존 문서를 전면 수정하지 않고 이번 확인 결과를 별도 기록한다.

- TU-Note: ‘링크 전부 404’에서 **현재 공식 배포 페이지·파일 목록 확인, 안내 PDF 다운로드 성공**으로 갱신한다.
- SyncViolinist: ‘공개 여부 불명’보다 구체적으로, 공식 GitHub가 데이터와 모델의 **이메일 요청 경로**를 안내한다. 하지만 bow direction/fingering 중심이므로 우선순위는 낮다. [공식 README](https://github.com/Kakanat/SyncViolinist).
- Philharmonia: 기존 ‘CC BY-SA 3.0, 자유 재배포’ 취지의 설명을 현재 공식 조건으로 뒷받침할 수 없다. 공식 페이지는 자유로운 활용과 commercial work 포함을 허용하면서 **샘플 그대로 판매·제공하는 것을 제한**한다. 이전 다운로드에 적용된 약관이 무엇이었는지는 별도 보관 증거가 필요하다. 이번 공개 재현 패키지는 원음 대신 파일명·hash·취득 경로를 제공하는 방향으로 설계한다. [현재 공식 Licensing](https://philharmonia.co.uk/resources/sound-samples/).
- OrchideaSOL: metadata의 CC BY 4.0과 오디오의 Ircam Forum License는 다르다. 공식 설명은 MIR 학습·평가 연구 사용을 명시한다. [공식 설명](https://zenodo.org/records/3686252).
- Erhu: 파일 2,523개를 새 독립 관측 2,523개로 세지 않는다. 11-class train 927개와 test 326개의 합계 1,253개를 다른 분류체계 폴더의 중복 경로 수와 구분하고 실제 manifest를 기준으로 한다.

**4. 추천 확보 경로와 판단 기준**

추천은 **보유 OrchideaSOL로 예제 준비 + TU-Note의 마이크 비교 가능성 점검 + 새 연주자 녹음 feasibility 확인**이다. 신청형 데이터는 먼저 metadata를 요청하고, 필수 조건이 맞는 경우에만 확보 일정을 잡는다. TU-Note는 source pilot의 보조 후보이며 새 데이터셋을 무조건 본 실험에 추가하자는 결정은 아니다.

| 단계 | 계획 규모 | 결과로 판단할 것 |
|---|---|---|
| 준비용 청취 예제 | 기존 자료 20쌍 | label 정의·변형 질문이 음악적으로 타당한가 |
| 새 녹음 pilot | 종별 1명, 4명 × 2세션 × 60개 = 480 clips | 실제 소요시간·희귀 주법 실행·녹음 품질·연주자 간 변동 |
| 최초 confirmation 계획 | pilot과 다른 종별 2명, 8명 × 2세션 × 60개 = 960 clips | 사전 고정한 주대조의 외부 확인 |
| 정밀도에 따른 사전 확장 | confirmation 종별 4명, 16명 × 2세션 × 60개 = 1,920 clips | pilot만으로 필요성을 결정하고 확인 결과 열람 전에 규모 고정 |

60개는 5주법 × 3음 × 2강약 × 2takes다. 이 방식이 pizzicato의 감쇠와 tremolo의 반복성을 왜곡하지 않도록 녹음 지시는 전문가와 확정한다. 모든 clip을 같은 길이로 무리하게 잘라 attack을 없애지 않는다. 두 mic를 동시에 받아도 연주자나 take 수는 늘어나지 않는다.

소요시간은 실제 예약·견적이 아닌 계산용 가정이다. 한 세션을 설명·설정·반복을 포함한 45–75분으로 잡으면, 4명 pilot은 녹음 슬롯 6–10시간, 총 12명 설계는 18–30시간이다. 장비 세팅·편집·전문가 평정 시간은 별도다. 60 clips × clip당 8초라는 보관 계산에서는 총 1,440 clean clips가 약 3.2시간이며 48kHz/24bit mono 원음 약 1.66GB다. raw continuous take·두 mic·변형·백업은 추가 용량이 필요하다. 녹음실이 실제로 확보됐다는 뜻은 아니다.

현금 비용은 지역·기관과 보상 기준을 모르는 상태라 견적을 만들지 않는다. `총액 = 세션 수 × 회당 보상 + 녹음실 시간 × 대관료 + 녹음 인력 + 전문가 평정 + 장비/교통비`로 산정한다. 무상 학내 공간·장비를 쓸 수 있는지가 비용을 크게 좌우한다.

모집 타당성 확인에 필요한 답은 네 가지다: (1) 네 악기종별 참여 의향자 수, (2) 같은 사람이 두 번 참여 가능한지, (3) 다섯 주법과 특히 col legno battuto의 실행 가능성, (4) 공간·장비·연구 이용 및 공개 범위. 참여자에게 악기나 활의 손상을 감수하도록 요구하지 않는다. 윤리·동의 절차는 실제 소속 기관의 기준으로 수집 전에 정한다.

**4주 판단 시점**: 종별 pilot 경로, confirmation 추가 모집 경로, 공간·장비, 데이터 사용 범위가 모두 구체화되면 진행한다. 하나의 악기만 확보되면 바이올린 등 한 악기 내 새 연주자 연구로 범위를 좁혀 계획을 다시 고정한다. 소수 연주자의 반복 clip 수를 늘려 네 악기종 일반화라고 보고하지 않는다. 새 연주자 확보 경로가 없으면 기존 데이터 기반의 제한된 스트레스 분석은 가능하지만 B 연구의 외부 확인은 보류한다.

**5. 문의 우선순위와 아직 모르는 것**

1. 사용자/지도교수의 실제 연주자·공간 네트워크: 확보 가능성을 결정하는 최우선 정보. 아직 답변으로 확인되지 않았다.
2. TU-Note: paired audio와 변형 연구에 대한 사용 조건을 확인. 데이터 배포 페이지와 PDF는 확보됐지만 ZIP 다운로드 완료 상태가 아니다.
3. Violin Technique Dataset: 이름보다 class vocabulary·player/session별 count table을 먼저 받기. 정답이 이번 주법들과 불일치하면 추가 다운로드 없이 종료.
4. mdw cello 프로젝트: 담당자 `pamies-vila@mdw.ac.at`는 공식 페이지에서 확인. 이미 수행한 전문 연주자 실험의 연구용 subset을 공유할 수 있는지 문의할 가치가 있다. 공유 승인은 미확인.
5. RWC-I: 학과 보유 자료 확인 → 관리기관에 현재 배포 여부 확인. 과거 주문 절차를 무검토 재사용하지 않음.

검토용 문의 문안은 `docs/phase5_data_access_questions.md`에 저장했다. 발송하지 않았다. 후보별 승인 가능성이나 응답 시간을 수치로 추정하지 않았다.

**검증 한계**: 공개 catalog 전체에 데이터가 없음을 증명한 조사는 아니다. 일부 Zenodo 요청은 429/접근 오류, TELMI/URMP 연결은 도구 접근 실패가 있었다. TU-Note PDF는 웹 도구 실패 후 허용된 네트워크 다운로드로 읽었다. 파일 다운로드를 확인하지 못한 후보는 ‘배포 안내 확인’으로만 기록했다. 모델 다운로드·학습·새 성능 추정은 없다.
