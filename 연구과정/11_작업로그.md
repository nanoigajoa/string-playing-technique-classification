## A3 — Surrogate fidelity 재계산 (in-sample 착시 → OOF κ) (2026-07-16)

- **문제 확인**: 0.998은 in-sample 착시. xgb_v1이 학습셋을 암기(in-sample 정확도 **1.0**)해
  MERT-LR(99.8%)과 자동으로 일치. 결정적으로 **오답 케이스 일치율 = 0/7**(둘이 틀리는 경우 안 겹침).
- **바꾼 것**: `phase3_shap.py`의 `compute_surrogate_fidelity`를 **악기 단위 GroupKFold OOF**로 재작성
  (xgb_v1과 동일 파라미터 max_depth7/n300/lr0.1/sub0.8). Cohen's κ + 오답 합집합 일치율 + 클래스별
  one-vs-rest κ 추가. 플롯도 OOF per-class κ로 교체.
- **수치 변화**: in-sample 0.998 → **OOF 일치율 0.914, Cohen's κ 0.882**. 오답 케이스(n=348) 일치율
  **0.16** — 두 모델은 서로 다른 클립에서 실패. 클래스별 κ: tremolo 0.97 최고, **sul_ponticello 0.74·
  col_legno 0.72**로 소수 클래스에서 대리 신뢰도 뚝. → "XGBoost는 MERT의 합리적이나 불완전한 대리,
  소수 클래스 해석은 주의" 로 착지.
- **갱신 문서**: `results/phase3/report.md` §3(전면 개편, in-sample 0.998을 교정 대상으로만 명시),
  `shap_surrogate_fidelity.png`(OOF κ), `docs/09_summary.md`, `docs/확장/03_phase3_shap.md`,
  `docs/확장/00_overview.md`, `docs/기여정리_선행연구대비.md`. Abstract급 문서에서 0.998 헤드라인 제거.

- **신규** `src/phase3_descriptor_probe.py` → `results/phase3/descriptor_probe.{md,csv,png}` +

### 결과 — 가설이 **절반만** 지지됨

- **지지됨 (메커니즘 서사의 핵심)**: onset-strength envelope R² = **L0에서 이미 0.767**.
  L0는 transformer 통과 전 **conv front-end 출력**이다. L1에서 0.820(+0.052), 그 뒤 12개 층이
  추가로 버는 건 **+0.030**(정점 L8 0.850). ZCR(L3 0.699 정점 후 L12 0.627로 하락),
  spectral contrast(거의 평탄 0.71~0.75)도 같은 모양. **MFCC는 L2 0.638 정점 후 단조 감소해
  L12 0.490(−0.148)** — 깊이가 오히려 파괴한다.
  → **판별에 쓰이는 저수준 물리량은 conv front-end에서 이미 선형으로 거의 다 가용**,
  깊이는 그 위에 아무것도 보태지 않음. parity의 메커니즘 설명으로 성립.
- **지지되지 않음 (중요, 서사에서 제외해야 함)**: "MERT가 기법 분류에 쓰는 층 = 음악가의 물리량이
  있는 층"이라는 **정렬(alignment) 주장**. B2 학습 가중과 층 프로파일의 Spearman ρ —
  core descriptor 전부 **ρ=0.38~0.43, p=0.14~0.19로 유의 아님**. 유일하게 유의한 건
  **음성 대조군 chroma(ρ=0.725, p=0.005)**. 12_ §6에 적어둔 반증 조건이 **부분 발동**.
  - 단, 검정력 해석 주의: 13점 Spearman이고 core 프로파일이 거의 평탄(range ≤0.08)이라 검정력이
    매우 낮다. 이는 **"정렬이 없다"의 증거가 아니라 "정렬을 주장할 수 없다"**이다. 그대로 서술할 것.
- **부수 발견 (대조군이 제 역할을 함)**: **chroma만이 깊이에 따라 상승**하는 유일한 그룹
  (L0 0.506 → L9 0.604, **+0.098**). 즉 **MERT의 깊이는 화성·음고 추상화를 벌고, 이 과제가 필요로 하는
  저수준 물리는 벌지 않는다.** 음성 대조군을 소극적 안전장치가 아니라 적극적 논거로 쓸 수 있음.
- **RMS 이상치 해명(검증 완료)**: RMS R²가 0.02~0.24로 비정상적으로 낮음 → 원인은
  MERT `Wav2Vec2FeatureExtractor`의 **`do_normalize=True`**(파형별 zero-mean/unit-var 정규화)로
  **절대 음량이 전처리 단계에서 제거**되기 때문. 코드로 확인함. 함의: 음량 의존 단서는 MERT에
  **구조적으로 불가용**한 반면 SVM(245d)에는 가용 — parity 논의에 쓸 수 있는 비대칭.
- **정합 확인**: `log_first_onset_time` R² ≈ 0~음수(전 층). A5에서 오구현 확인 + SHAP 최하위(7/7)였던
  특징이라 **독립적으로 정합**. 이 특징이 실제로 정보를 담지 않음을 재확인.

### 착지 수정 (12_ §3 반영 필요)

- 채택: **"저수준 물리는 conv front-end에서 포화 / 깊이는 화성 추상화만 번다 → 이 과제에서 깊이는

## B6 — 클러스터 부트스트랩 CI + **재표집 단위가 결론을 뒤집는 발견** (2026-07-21)

- **신규** `src/phase1_cluster_bootstrap.py` → `results/phase1/cluster_bootstrap.{md,csv}`,
  `cluster_bootstrap_2level.csv`, `bootstrap_preds.npz`. 2단계 구조(`--stage preds|boot|all`).
  1단계는 감사(A1) 분할을 재현하고 **감사 CSV가 고른 best config만 재적합**(24-config 그리드
  재탐색 없음, 48 split 9초) → per-clip 예측 저장. 2단계는 부트스트랩.
- **재현 점검**: SVM은 완전 재현(Δ ~1e-16). MERT는 head 학습이 확률적이라 **mean Δ −0.008,
  max |Δ| 0.075**. 재적합은 감사와 동일 분포의 또 다른 추출로 간주하고 Δ를 리포트에 명시.

### 핵심 발견 — 부트스트랩 **재표집 단위**가 결론을 바꾼다

| 대비 (동일 학습데이터, 주 비교) | 차이 | 1수준 CI (클립/클러스터만) | 2수준 CI (fold 포함) |
|---|---|---|---|
| 5% | −0.027 | [−0.044, −0.012] **0 제외** | [−0.107, +0.050] 0 포함 |
| 10% | −0.000 | [−0.016, +0.015] 0 포함 | [−0.071, +0.069] 0 포함 |
| 20% | −0.026 | [−0.043, −0.011] **0 제외** | [−0.074, +0.035] 0 포함 |
| 50% | −0.007 | [−0.021, +0.006] 0 포함 | [−0.046, +0.025] 0 포함 |

- **1수준**(recording_id 클러스터 재표집, BCa): 5%·20%에서 **SVM이 유의하게 앞선다**는 결론이 나온다.
  겉보기엔 Kruger급 엄밀성(BCa 부트스트랩)이라 통과할 법하다.
- **그러나 이 구간은 test 클립 표집 변동만 담는다.** fold(=악기)와 labeled 추출은 고정으로 취급 —
  즉 **"다른 악기에서도 같은 결론인가"에 답하지 않는다.** 이 논문의 주장은 악기를 넘어선 일반화이므로
  fold 간 변동이 **지배적 분산 성분**이고, 그것이 빠져 있다.
- **2수준**(fold 복원추출 → 각 fold 내 클러스터 재표집): 주 비교 **4개 구간 전부 0 포함**.
  부트스트랩 SD가 **2.6~5.0배** 넓어진다. → **parity 유지**, fold-std(n=4) 분석과 일치.
- **논문 함의(큰 것)**: 이건 함정 ①(선택-시점 누수)·②(백본 언더튜닝)에 이은 **세 번째 함정 후보** —
  *"불확실성 정량화의 재표집 단위를 잘못 잡으면, 방법론적으로 흠잡을 데 없어 보이는 CI가
  없는 차이를 유의하게 만든다."* 우리 데이터에서 실제로 발동했고 before/after 표까지 나온다.
  **주의**: 1수준 결과를 서랍에 넣지 말고 **둘 다 싣는 것**이 논지다.

### 설계 메모

- 재표집 단위 = `recording_id`(같은 음고·강약 녹음). fold별 test 클러스터 135~147개.
- fold 내 test set이 모든 (ratio, trial)에서 동일함을 assert로 검증 → 재표집을 fold 단위로 공유.
- 모델 간 차이는 **동일 재표집에서 계산한 대응(paired) 차이** — 상관 보존.
- 집계 경로는 주 수치와 동일(trial 평균 → fold 평균). 1수준은 BCa(가속도는 클러스터 jackknife 567개),
  2수준은 percentile(계층 구조에서 jackknife 정의가 모호해 BCa 미적용 — 한계로 명시할 것).
