```python
def extract_region_features(y, sr):
    onsets = librosa.onset.onset_detect(y=y, sr=sr, units='samples')
    onset_idx = onsets[0] if len(onsets) > 0 else 0
    attack_window = int(0.05 * sr)
    y_attack = y[max(0, onset_idx - attack_window):onset_idx + attack_window]
    y_sustain = y[onset_idx + attack_window:]
    # 각 구간별 flux / mfcc 독립 추출
```

**작업**: `src/features.py`에 함수 추가 → v1 SVM/XGBoost 재학습 → LOSO 평가 비교.
