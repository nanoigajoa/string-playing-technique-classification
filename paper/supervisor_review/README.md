# 선생님 검토용 첨부 자료

준비일: 2026-10-07. 권장 첨부는 다음 PDF 두 개다.

1. [국문 원고 v2 — 19쪽](../manuscripts/v2/review_ko_v2.pdf): 본문·방법·그림·표를 검토할 원고.
2. [투고 검토 요약 — 2쪽](투고검토요약_20261007.pdf): 주요 결과·기여 범위·선행연구 대조·투고 후보·보강안·검토 요청.

요약의 [편집 가능한 Word](투고검토요약_20261007.docx)와 [Markdown 원본](투고검토요약_20261007.md)도 보관한다. Word 앱에서 실제 쪽수는 확인하지 않았으며 ‘2쪽’은 PDF의 쪽수다.

투고처별 판단의 자세한 문헌 근거와 확인 범위는 [28번 기록](../../연구과정/28_레거시논문_대조_및_투고처판정.md)에 있다. [25번 계획](../../연구과정/25_국내외_투고처_결정_및_검증_계획.md)의 네 검증은 현재 채택한 canonical 결과에 대해 완료했다. 공통 분류기 대조는 미실행 선택적 보강안이며 확정된 다음 작업이나 공통 투고 필수 조건이 아니다. 요약의 투고 권고는 검토 의견이며 선생님의 최종 판단을 요청하는 자료다.

선생님의 요청에 맞춘 [답장 파일](선생님_답장_논문지후보_및_투고검토_20261007.md)은 이미 완료한 검증과 현재 기여, 유사 논문의 게재 사례를 중심으로 작성했다.

PDF의 두 페이지를 이미지로 확인했고 한글·표·참고문헌의 배치와 글꼴 포함 여부를 확인했다. Word ZIP 무결성과 PDF의 주요 수치·텍스트를 검사했다. [manifest.json](manifest.json)에 원본·PDF·Word의 SHA-256을 기록했다. 메일은 발송하지 않았다.

저장소 루트에서 다음 명령으로 요약을 다시 생성할 수 있다. Matplotlib과 pandoc, macOS의 AppleGothic 글꼴을 사용한다.

```bash
MPLCONFIGDIR=/private/tmp/phase1-supervisor-mpl-cache \
XDG_CACHE_HOME=/private/tmp/phase1-supervisor-cache \
/private/tmp/phase1-release-venv/bin/python src/phase1_supervisor_brief_export.py
```

메일 본문에 덧붙일 문장:

> 원고와 함께 주요 결과, 완료한 투고 전 검증, 선행연구 대비 기여와 논문지별 검토 의견을 정리한 2쪽 요약을 첨부드립니다. 현재 결과와 기여에 맞는 투고처 및 원고 구성 방향에 대해 의견을 부탁드립니다.
