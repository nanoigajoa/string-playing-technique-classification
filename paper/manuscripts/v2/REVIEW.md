## v0·v1에서 바꾼 내용

핵심 질문을 ‘제한 라벨의 악기종 보류 조건에서 두 분류 구성의 성능과 오류가 어떠한가’로 정리했다. v0의 음악적 배경, 직접 관련된 선행 연구, 특징과 분할의 설명을 검토해 복원했다. v1의 수치와 출처를 기준으로 악기종별·주법별 결과, 집계 방식, 자기학습과 oracle의 의미를 자세히 설명했다.

본문은 7개 절, 그림 6개, 본문 표 5개, 부록 표 2개, 참고문헌 11편으로 구성된다. 최초 작성본의 10편에 MERTech 프리프린트를 추가했다. 부록에는 전체 라벨 CNN과 실제 분할 크기를 보존했다.

| Markdown 원고 | 문자 수 | 공백으로 나눈 토큰 수 | 그림 |
|---|---:|---:|---:|
| 국문 v0 | 32,602 | 6,290 | 4 |
| 국문 v1 | 10,911 | 1,965 | 3 |
| 국문 v2 최초 작성본 | 26,649 | 5,737 | 6 |
| 국문 v2 내용 검토 후 | 28,513 | 6,109 | 6 |

공백 토큰 수는 한국어 원고의 기계적 비교용이며 영문 단어 수나 학술지 분량 판정이 아니다. v0에서 근거가 부족한 해석·과거 수치·별도 탐색 주제를 제외했으므로 모든 문단을 그대로 복원한 것은 아니다.

**제외한 근거:** 결함별 인과 효과를 입증하지 못한 ‘두 번의 반전’, 동등성 주장, 현재 MERT/SVM의 기전으로 연결되지 않는 SHAP·층별 프로브, 별도 검증 범위가 필요한 LoRA·ALM·외부 전이. CNN은 라벨 예산이 다르므로 본문의 직접 순위 비교에서 제외하고 부록으로 옮겼다. 비용 우위·실제 연주·교육 효과도 측정 결과로 주장하지 않는다.

## 그림 검토

| 번호 | 역할 | 입력과 표시 기준 |

| 1 | 악기종×주법 분포 | 경로 제거 메타데이터, 고유 클립 3,402개. 셀 숫자·색은 같은 수량 |
| 2 | 분할·선택·평가 절차 | 코드 기반 설계도. 64/16/20%는 관측 시드 내부 근사 비율. SVM에는 조기종료 없음 |
| 3 | 예산별 평균 | 튜닝 MERT/SVM과 고정 자기학습을 별도 패널로 표시. 두 패널 y축 동일, 예산은 범주 축 |
| 4 | 평균에 가려진 차이 | 악기종별 세 반복 평균과 50% 주법별 F1. 유의성 표시 없음 |
| 5 | 오류 방향 | 50% MERT/SVM과 5% 감독/의사 라벨. 각 패널 10,206개 반복 예측, 행 정규화, 공통 0–1 색 범위 |
| 6 | 재표집 민감도 | 같은 점추정에 대한 세 단위, 1,000회 percentile. 12개 MERT−SVM 구간 모두 0 포함 |

각 그림을 PNG 300 dpi와 글꼴을 포함한 PDF로 생성했다. 국문 축·제목·범례, 축 범위와 범주 간격, 클래스 순서, 소수점 반올림, 집계 단위를 확인했다. 인쇄 크기에서 읽기 쉽도록 범례·셀 숫자·도식 글자를 키웠다. 색과 마커를 함께 사용하고 그림 5의 모든 패널에서 동일 색 범위를 적용했다. 입력·출력 해시는 [figures/manifest.json](figures/manifest.json)에 기록했다.

최초 작성본 PDF의 17쪽을 이미지로 확인했다. 10월 5일 수정본은 표지·초록 포함 19쪽이다. 모든 페이지를 렌더링한 축소 모음에서 배치를 확인하고, 변경한 결과·논의·한계·결론 페이지는 개별 이미지로 확대 확인했다. 그림과 캡션, 표와 표제의 분리·잘림은 발견하지 않았고 모든 그림은 해당 캡션과 같은 페이지에 배치됐다. Word는 ZIP 무결성과 표·그림 구조를 확인했다. Word 앱의 글꼴 환경에 따른 쪽수까지 PDF와 같다고 보장하지 않는다.

## 수치와 재현 검토

- 저장 예측 전용 재계산을 다시 실행했다. 100개 예측 파일, 244개 모델 예측 벡터, 10개 표·878행이 절대 허용 오차 1e-12 이내에서 기존 자료와 일치했다. 새 학습이나 checkpoint 추론은 이번 작성에서 수행하지 않았다. [실행 결과 JSON](REPRODUCTION.json)
- 국문 표 1·2·4·5·A1·B1을 메타데이터·CSV·manifest와 대조했다. 표 3의 학습·탐색 설정은 실행 코드를 읽어 대조했다.
- 국문 DOCX에 표 7개·그림 6개, HTML에 내장 그림 6개가 존재하며 DOCX ZIP 무결성이 통과했다. PDF에서 6개 캡션, 핵심 수치, 한글과 부록·참고문헌을 확인했다.
- 검증 결과는 [VERIFICATION.json](VERIFICATION.json), 편집 원본·DOCX·HTML·PDF·생성 코드의 해시는 [artifact_manifest.json](artifact_manifest.json)에 있다.
- 10월 5일에는 수치 표·그림 해시·출력 구조를 재대조했다. 5% 의사 라벨−감독 클래스 F1 차이 다섯 개를 원자료와 확인했고, 변경 문장 다섯 개가 Markdown·DOCX·HTML·PDF에 반영됐는지 검사했다. 이 검토에서는 새 학습·checkpoint 추론이나 전체 bootstrap 재실행을 하지 않았다.

## 다시 생성하기

저장소 루트에서 실행한다. 수치 그림에는 NumPy·pandas·Matplotlib, 원고 내보내기에는 pandoc과 로컬 브라우저가 필요하다.

```bash
python src/phase1_paper_v2_figures.py
python src/phase1_paper_v2_export.py
# review_ko_v2.html을 Chrome에서 A4로 인쇄; 브라우저 기본 머리글·바닥글은 끈다.
python src/phase1_paper_v2_verify.py
```

기존 분석 가상환경 `/private/tmp/phase1-release-venv`에서 그림과 통계 재계산을 실행했다. 정확한 PDF 출력을 위해서는 현재 HTML의 CSS와 한글 글꼴을 사용한다. PDF·DOCX·그림을 수정하면 검증과 해시를 다시 갱신한다. v2는 `paper/manuscripts/v2/`에서 관리하며 기존 v0·v1 내보내기 경로와 자동 동기화하지 않는다.

## 2026-10-05 내용 검토 완료

연구 기여·음악적 해석·초록/서론/결론의 연결을 검토하고 본문에 반영했다. 기여를 조건부 비교 결과와 재현 자료로 구체화하고, 직접 선행 사례인 MERTech를 보완했다. 5% 자기학습의 하락이 다섯 클래스 모두에 나타난다는 관찰, 시간 평균 이전의 시간 차분·문맥 정보, 사전학습 자료 중복을 확인하지 못했다는 한계를 추가했다. 수치 요약과 기존 그림은 유지했다.

현재 원고는 이 자료·실행 정책의 경험적 비교를 제공한다. 새로운 분류법이나 음향적 원인을 입증한 연구로 판단하지 않으며, 특정 학술지에 충분한 독립 기여인지 확정한 것도 아니다. 자세한 기여·문헌·오류 근거와 검토 판단은 [27번 기록](../../../연구과정/27_국문v2_기여_음악적해석_검토.md)을 따른다.

다음 집필 단계는 영문 v2 대응본이다. 저자의 최종 기여 판단, 저자·소속·지원·이해상충·AI 도구 사용 선언, 공개 자료의 라이선스·주소와 실제 투고 형식 점검은 남아 있다. 국문 v2 내용 검토 완료가 외부 자료 공개나 학술지 제출을 의미하지 않는다.

## 2026-10-07 투고처·기여 충분성 후속 판정

[28번 기록](../../../연구과정/28_레거시논문_대조_및_투고처판정.md)에서 기존 게재 논문의 기여 단위와 현재 결과를 대조했다. 좁은 국문 구성 비교로는 멀티미디어학회논문지를 현재 1순위로 권고하고, 해외 보강 후보로는 MLWA를 권고한다. TISMIR와 JNMR는 현 상태의 1차 제출을 권하지 않는다. 기여의 충분성은 검토자의 판단이며 게재 보장이 아니다.

이에 따라 위의 ‘다음은 영문 v2’는 해외 투고를 선택하는 경우의 집필 단계로 해석한다. 현재 결과를 먼저 논문화하는 권고 경로는 국문 학회지 형식의 비교 원고 준비다. 이 후속 판단에서는 원고 본문·수치·DOCX·PDF를 변경하지 않았다.
