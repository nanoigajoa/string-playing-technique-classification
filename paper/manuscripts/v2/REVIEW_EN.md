## 번역 기준과 범위

사용자가 지정한 [국문 v2 PDF](review_ko_v2.pdf)와 같은 내용의 국문 Markdown을 기준으로 전체 원고를 영문으로 옮겼다. 국문 원본과 PDF가 기존 artifact manifest의 SHA-256과 일치함을 먼저 확인했다. 초록·본문 7개 절·참고문헌 11편·부록 A/B와 그림 6개·표 7개를 모두 포함했다.

국문·영문 원고의 Markdown 블록 141개, 절·소절 제목 30개가 대응한다. 수치·표·수식과 주장의 적용 범위를 유지했다. 영문 원본의 공백 기준 분량은 제목·검토 메타데이터·표·캡션·참고문헌을 포함해 7,381단어다. 이는 특정 저널의 최종 분량 판정을 대신하지 않는다.

평가 그룹은 `instrument type`, 라벨 예산은 `observed-label budget`으로 옮겼다. 관측 라벨 안의 학습·조기종료·설정 선택을 구별하고, 세 반복이 독립 테스트 자료라는 표현을 사용하지 않았다. Oracle은 숨은 정답을 제공하는 진단이며 성능 상한이 아니고, 재표집 구간의 0 포함은 모델 동등성을 입증하지 않는다는 설명을 유지했다. 음향 기전·새 연주자/세션·실제 연주에 관한 미확인 범위도 유지했다.

새 문헌·실험 결과나 투고처 판단을 본문에 추가하지 않았다. 영문 생성 정보를 표지 메타데이터와 재현성 설명에 덧붙였다. 이번 번역은 영어 v1을 확장한 것이 아니라 국문 v2 전체의 대응본이다.

## 그림과 수치 확인

그림 안의 축·범례·제목·도식 문구도 영문으로 생성했다. 기존 수치 계산 코드를 사용하고 표시 문구·글꼴·읽기 크기를 조정했다. `figures_en/`에 PNG 300 dpi와 글꼴을 포함한 PDF를 보관한다. `tables_en/`의 CSV 9개는 기존 국문 그림용 CSV와 행·열·값이 모두 같다. 입력과 출력 해시는 [그림 manifest](figures_en/manifest.json)에 있다.

- 국문·영문의 표 7개에서 수치와 범위가 일치한다.
- 각 대응 블록의 소수 값·부호·출현 횟수를 대조했다. 수식 2개는 원문과 동일하다.
- 참고문헌 11편의 저자 표기와 출처 링크가 같은 순서로 대응한다.
- DOCX ZIP 무결성, 표 7개·그림 6개, HTML의 내장 그림 6개를 확인했다.
- 영문 PDF에서 본문 표의 주요 값·그림 캡션·참고문헌·부록 및 핵심 한계 문장을 대조했다. 원고와 그림 PDF에 한글이 남지 않았음을 확인했다.
- 국문 원고·PDF·Word·그림·기존 검증 파일과 사용자가 편집한 메일은 작업 시작 때의 해시와 같았다.

이는 번역·산출물의 정합성 검토다. 새 모델 학습·checkpoint 추론·bootstrap 재실행은 수행하지 않았다. 기존 모델 검증과 결과 재계산의 범위는 국문 검토 기록을 따른다.

## PDF 배치 검토

최종 PDF는 A4 19쪽이다. 19쪽 전체를 이미지로 렌더링해 축소 페이지 모음으로 배치를 확인했고, 분할 도식·수식·혼동행렬·부록 페이지는 개별 이미지로 확대 확인했다. 그림 여섯 개가 각각 캡션과 같은 페이지에 있으며 표제·표·수식의 잘림은 발견하지 않았다. `pdffonts`에서 PDF의 모든 글꼴이 포함됐음을 확인했다.

Word는 편집 가능한 구조를 검사했으나 Word 앱의 실제 쪽수·배치를 확인한 것은 아니다. 현재 출력은 원문의 내부 검토본 지위를 유지한다.

## 다시 생성하기

저장소 루트에서 실행한다. 그림 생성에는 기존 분석 환경의 NumPy·pandas·Matplotlib, 문서 내보내기에는 pandoc, PDF 출력에는 Python Playwright와 로컬 Chrome을 사용했다.

```bash
XDG_CACHE_HOME=/private/tmp/phase1-en-v2-cache \
/private/tmp/phase1-release-venv/bin/python src/phase1_paper_v2_en_figures.py
python3 src/phase1_paper_v2_en_export.py --pdf
python3 src/phase1_paper_v2_en_verify.py
```

영문 그림·표와 원고 출력은 `figures_en/`, `tables_en/`, `review_en_v2.*`에 생성한다. 국문 출력 경로에 덮어쓰지 않는다. 원고·그림·생성 코드를 수정하면 출력·대조와 해시를 갱신한다.
