국문 v2는 v0의 배경·방법을 검토해 복원하고 v1의 canonical 근거로 재구성한 전체 초안이다. 그림 6개, 본문 표 5개와 부록 표 2개, 참고문헌 11편을 포함한다. 10월 5일 [연구 기여·음악적 해석 검토](../연구과정/27_국문v2_기여_음악적해석_검토.md)를 완료하고 본문과 출력본에 반영했다. 영문 v2는 이 국문 전체 원고의 대응본이며 그림 내부 문구도 영문으로 생성했다. 표 7개·수식·문헌·수치와 주장 범위를 대조했다. 두 언어 모두 내부 검토본이다.

10월 7일 [기존 논문 대조 및 투고처 판정](../연구과정/28_레거시논문_대조_및_투고처판정.md)은 현재 결과의 좁은 국문 비교 논문으로 멀티미디어학회논문지, 공통 분류기 대조를 보강한 해외 후보로 MLWA를 권고한다. TISMIR 우선 계획을 현재 v2에 자동 적용하지 않으며, 실제 투고처 확정·양식 편집·제출은 아직 수행하지 않았다.

선생님 검토용으로 [원고와 함께 보낼 자료 안내](supervisor_review/README.md)와 [투고 검토 요약 PDF — 2쪽](supervisor_review/투고검토요약_20261007.pdf)를 준비했다. 요약의 편집 가능한 Word와 원본도 같은 폴더에 있다.

**v1 canonical은 검증된 결과를 중심으로 축약한 검토본**이다. v0의 과거 수치와 일부 주장은 이후 검증에서 수정·보류되었으므로, 현재 결과는 [검증 보고서](notes/report.md)와 [주장 감사 기록](notes/manuscript_claim_audit.md)을 함께 확인한다. 아래 폴더의 v0·v1은 보관본이고, 현재 국문 집필·출력본은 위의 v2를 사용한다.

## 폴더 구성

- `manuscripts/v0/`: 초기 국·영문 전체 초안, Markdown와 DOCX 각 2개.
- `manuscripts/v1_canonical/`: v1 국·영문 검토 원고, Markdown와 DOCX 각 2개.
- `manuscripts/v2/`: 국문·영문 전체 원고·DOCX·PDF·HTML, 그림·표·검토 및 생성 기록. 영문 그림·표는 `figures_en/`, `tables_en/`에 있다.
- `manuscripts/early_drafts/`: 아웃라인, 절별 초안, 초기 통합 원고.
- `pdf/`: 현재 영문 검토 PDF와 `legacy/`의 초기 요약 PDF.
- `preview/`: 영문 검토 HTML·Markdown·스타일시트.
- `figures/canonical/`: 현재 그림 3개의 PNG·PDF와 생성 manifest.
- `figures/legacy/`: v0에서 참조하는 과거 그림 4개.
- `notes/`: 원고 준비 상태, 기여 범위, 주장·결과 검증 기록.
- `notes/reproduction/`: 저장 예측 재계산의 검증·환경 기록.

## 보관 기준

`연구과정/`의 워드 파일 4개를 모두 포함했다. 원고 내용은 유지했고, 복사된 Markdown에서 상대 링크와 그림 경로만 새 위치에 맞췄다. DOCX·PDF·HTML·그림은 원본과 바이트가 같다. 기존 `연구과정/`과 `results/` 파일도 유지했다.

원본 위치·복사 위치·SHA-256·경로 변경 내역은 [inventory.json](inventory.json)에 있다. `notes/original_artifact_manifest.json`과 그림 manifest는 원래 생성 위치의 기록이므로, 이 폴더의 복사본 대조에는 `inventory.json`을 사용한다. 복사한 검토·재현 기록에 적힌 코드 경로와 명령은 저장소 루트를 기준으로 한다.

v0·v1 복사본은 정리 시점의 보관본이며 자동 동기화되지 않는다. 기존 v1 생성 스크립트는 계속 `연구과정/`과 `results/`에 출력한다. v2는 `paper/manuscripts/v2/`를 편집·출력 위치로 사용하며, 생성 방법과 별도 해시는 해당 폴더의 검토 기록을 따른다. `inventory.json`은 최초 복사한 43개 파일의 기록이며 이후 추가한 v2 산출물 목록이 아니다. 선행 연구 PDF와 재현 묶음 안의 중복 원고는 원래 위치에 보관한다.
