# 국문 v2 집필 기준 — v0·v1 및 근거 자료 분석

작성일: 2026-10-02. 이 문서는 국문 v2를 쓰기 위한 분석·편집 기준이다. 새 실험 결과나 v2 본문이 아니다.

**목표는 현재 확보한 결과로 현악 주법 분류의 성능과 한계를 일관되게 설명하는 국문 전체 원고를 완성하는 것이다.** v0의 배경·방법 설명을 검토해 살리고, 결과와 결론은 v1의 canonical 근거에 맞춘다. 이전 계획에 등장하는 후속 연구는 이 원고의 집필 조건에 추가하지 않는다.

## 1. 원고의 중심을 하나로 정하기

**핵심 질문:** 라벨이 제한되고 학습에서 보지 않은 악기종을 평가할 때, 음향 특징 기반 SVM과 고정 MERT 표현 기반 분류기는 어떤 성능과 오류 양상을 보이는가?

제안 제목: **「제한 라벨 조건의 현악 주법 분류: 악기종 보류 평가에서 음향 특징과 사전학습 표현의 비교」**

연구 목적 문장:

> 본 연구는 OrchideaSOL의 네 현악기종과 다섯 주법을 대상으로, 한 악기종을 보류하는 평가에서 라벨 예산에 따른 특징 기반 SVM과 고정 MERT 표현 기반 분류기의 성능 및 오류 양상을 비교한다. 같은 자료에서 관측 라벨의 학습·검증 역할을 구분하고, 자기학습 대조 실험과 재표집 민감도 분석을 통해 관찰 결과의 적용 범위를 검토한다.

본문의 역할은 다음처럼 연결한다.

- **주요 결과:** 라벨 예산에 따른 MERT/SVM 비교와 악기종·주법별 오류.
- **보조 질문:** 같은 예산에서 의사 라벨로 미라벨 자료를 활용했을 때의 변화. 자기학습 내부의 감독·의사 라벨 조건을 비교한다.
- **신뢰성 근거:** 라벨 접근, 전처리, 검증 선택, checkpoint와 저장 예측의 일치 및 재표집 단위.

평가 감사는 방법과 재현성에 통합한다. 구현 결함을 고친 이력을 연구 전체의 새로움으로 내세우려면 결함별 통제 효과가 필요한데, 현재 결과에는 그 증거가 없다. 현재의 기여는 이 특정 평가 조건에서 얻은 추적 가능한 비교 자료와 해석 범위로 기술한다.

## 2. v0·v1의 장점과 논리적 문제

| 항목 | v0 | v1 | 국문 v2 결정 |
|---|---|---|---|
| 문제 제기 | 현악 주법과 음향 특징의 맥락이 풍부함. 파운데이션 모델의 보편적 우월성을 전제로 세움 | 곧바로 감사 질문으로 들어가 연구 동기가 짧음 | 주법 인식의 필요성 → 라벨 제약 → 악기종 변화 → 두 분류 접근의 비교 순서로 작성 |
| 중심 논증 | 세 함정 → 결론 반전 → 동급 → 저수준 단서가 원인이라는 연쇄 | 검증된 비교와 주장 제한을 중심으로 축약 | 라벨 예산 → 평균 성능 → 악기종·주법별 차이 → 해석 범위의 흐름으로 재구성 |
| 방법 | 상세하지만 과거 실험과 현재 실험이 섞여 있음 | 현재 설정은 구체적이나 한 절에 압축됨 | 현재 실행 코드·manifest에 맞춰 데이터, 분할, 모델, 선택, 지표를 나누어 설명 |
| 결과 | 과거 수치·LoRA·프로브·외부 전이를 함께 사용 | canonical 표 2개와 그림 3개에 연결됨 | v1 수치를 기준으로 설명을 늘리고, 저장된 악기종·주법별 결과를 활용 |
| 논의 | 음악적 해석이 풍부하지만 상관·복원 가능성을 원인으로 확장 | 절차와 한계에 치우쳐 결과의 의미가 짧음 | 실제 오류 패턴을 먼저 설명하고 음악적 해석은 가설 수준을 표시 |
| 관련 연구 | 넓은 문헌과 비교표가 있으나 신규성·우열 판단이 과함 | 6편으로 좁아 논문 맥락 설명이 부족함 | 본문에서 실제로 쓰는 문헌을 원문 근거와 함께 복원 |

v0의 핵심 논증은 첫 연결부터 문제가 있다. 여러 구현·분할·설정이 함께 바뀐 결과 차이를 특정 결함의 인과 효과로 해석할 수 없다. 이어서 구간의 0 포함을 동등성으로 바꾸거나, 서술자 복원 가능성을 분류 결정의 원인으로 바꿀 수도 없다. 마지막 한계 절에 단서를 붙이는 것만으로 본문의 강한 결론이 성립하지는 않는다.

v1은 결과 출처와 수치 일관성의 기준으로 쓸 수 있다. 다만 연구 목적·배경·논의가 충분히 전개된 최종 본문으로 보기는 어렵다. v2에서는 v1의 방어 문장을 반복하는 대신 독자가 실험을 이해하는 데 필요한 설명을 채운다.

## 3. 확인한 근거와 v2에 쓸 수 있는 설명

### 데이터와 비교 조건

경로를 제거한 메타데이터에서 **3,402개 클립**, 바이올린 879·비올라 933·첼로 757·콘트라베이스 833개를 확인했다. 클래스 수는 ordinario 1,193·pizzicato secco 639·tremolo 1,041·sul ponticello 302·col legno battuto 227개다. [메타데이터](../results/phase1/canonical/release/canonical-reproduction/data/release_meta.csv)

MERT/SVM의 학습 index와 설정 선택용 index는 같은 분할을 사용한다. MERT는 고정된 마지막 층 표현을 시간 평균한 768차원 입력에 헤드를 학습한다. 따라서 이 실험의 대상은 **고정 MERT 표현+헤드와 245차원 특징+SVM이라는 두 분류 구성**이다. 차이를 표현만의 효과로 분리하거나 MERT의 모든 활용 방식에 일반화하지 않는다. [비교 코드](../src/phase1_canonical_mert_svm.py), [표현 추출 코드](../src/phase1_selftraining.py)

5% 예산은 외부 테스트를 제외한 자료에서 확보한 관측 라벨의 비율이다. 이 안에서 검증 라벨을 다시 떼므로 직접 학습에 쓰는 수는 더 작다. 48개 실행의 manifest를 확인했을 때 5% 조건의 실제 학습 표본은 78–85개, 조기종료 검증은 20–21개, 설정 선택 검증은 25–26개다. 소규모 검증에 따른 선택 변동 가능성을 논의하되, 그것이 성능 차이의 원인이라고 단정하지 않는다. [실행 manifest](../results/phase1/canonical/mert_svm/manifests/)

### v1에서도 다듬어야 하는 표현

- **Oracle 결과의 원인:** v1은 oracle이 항상 높지 않은 이유를 채택 경로와 검증 선택의 변화로 설명한다. 코드상 경로가 달라질 수 있는 것은 확인되지만, 어느 요인이 관찰된 차이를 만들었는지는 분리 검증하지 않았다. ‘항상 높지는 않았으며, 이 절차는 성능 상한을 보장하지 않는다’까지 결과로 쓰고 가능한 이유는 해석으로 표시한다.
- **두 MERT 점수의 혼동:** 튜닝 MERT와 자기학습의 감독 대조군은 헤드·내부 분할 시드·학습 설정이 다르다. 0.6655와 0.6686을 동일 기준선의 불일치로 보거나 두 표를 직접 이어 붙이지 않도록 설명한다.
- **학습 예산의 범위:** 제한 라벨 예산에는 조기종료·설정 선택 라벨도 포함한다. MERT 사전학습 자원은 이 예산에 포함되지 않는다. 24개/12개 설정 수가 동일 계산 비용이나 최적 튜닝을 뜻하지도 않는다.
- **평가 단위:** macro F1은 클래스별 F1의 평균이며, 보고치는 같은 악기종의 3회 실행을 평균한 뒤 네 악기종을 같은 비중으로 평균한다. 합산 혼동행렬에는 클립당 3회 예측이 들어가므로 10,206개를 독립 음원 수로 쓰지 않는다.
- **적용 범위:** 고립 음의 악기종 보류 결과다. 실제 연주 구절·새 연주자·새 세션에서의 성능이나 교육적 효과는 측정하지 않았다.

## 4. v0에서 복원할 내용과 근거가 부족한 내용

| 대상 | 처리와 이유 |
|---|---|
| 다섯 주법의 연주 방식과 음향적 구분 | 서론·데이터 절에서 복원. 동작·발음 방식의 정의를 정확히 쓰고 음악적 가설과 모델의 검증된 동작을 구분 |
| 특징군 설명, 분할 도식, 라벨 예산 | 현재 코드에 맞춰 복원. `flux`는 onset-strength envelope, 첫 onset 시각은 attack time과 구분 |
| 선행 주법 분류와 사전학습 표현의 배경 | 문헌 원문에 실제 근거가 있는 범위에서 복원. 발표 점수를 서로 다른 과제 간 순위로 사용하지 않음 |
| ‘두 번의 반전’, ‘동급’, ‘깊이가 도움이 되지 않음’ | 현재 근거가 지지하지 않는 결론. v2의 제목·초록·결론에서 사용하지 않음 |
| SHAP을 통한 MERT/SVM 기전 설명 | 현재 코드의 SHAP 대상은 별도 XGBoost 모델. 일치도 비교의 MERT 측도 canonical 헤드가 아닌 logistic probe이므로 현재 두 모델의 설명 근거로 연결할 수 없음 |
| 층별 서술자 프로브 | 서술자를 복원할 수 있다는 관찰과 분류기가 그 정보를 사용한다는 주장은 다름. 낮은 층 R²로 깊이의 불필요성을 입증할 수 없음 |
| LoRA·층 가중·외부 전이·ALM 결과 | 현재 핵심 질문에 필요한 검증 범위를 완료하지 않은 과거 탐색. 이번 v2의 결론을 뒷받침하는 결과에 편입하지 않음 |
| 전체 라벨 CNN | 본문 주요 비교의 중심에서 내려 별도 참고 결과로 배치. 전체 라벨 조건 F1 0.8729임을 명시 |
| ‘싸고 효율적인 모델’, ‘온셋이 유일한 핵심’, ‘길이 영향 제거’ | 비용 측정·특징 개입·검증된 교란 통제 없이 확정할 수 없는 주장. 시간 평균·클립 길이·집계 특징의 영향은 한계로 설명 |

SHAP 대상과 일치도 비교는 [분석 코드](../src/phase3_shap.py)의 `load_data`, `compute_shap`, `surrogate_fidelity` 관련 부분을 확인했다. 이전 [연구 감사](../연구과정/23_음악AI_연구방향_및_투고가능성.md) §9.5에도 이 문제가 기록되어 있다. [제외 모델 기록](notes/excluded_models.md)은 LoRA·층 가중 모델의 검증 범위를 설명한다.

문헌 노트도 검증 자료로 자동 승격하면 안 된다. 이번에는 다음 세 논문의 로컬 PDF에서 관련 부분을 직접 대조했다.

- **Kruger & Jacobs:** 층화 무작위 70/30 평가를 원문 PDF 7쪽에서 확인했다. 특징 기반 현악 주법 분류의 선행 맥락으로 활용할 수 있다. 다른 데이터·클래스·분할의 성능을 우리 수치와 직접 비교하지 않는다. [로컬 PDF](<../논문/06_SSL_Evaluation_Methodology/[2020_JNMR] Kruger_BowedStringPT_DHT_SVM.pdf>)
- **MERT:** PDF 6쪽의 고정 백본과 MLP probing, 17쪽의 MARBLE 기반 탐색 설명을 확인했다. 저장소 요약 노트의 ‘MARBLE 프로토콜 기준으로 비교하지 않았다’는 문장은 이 원문과 맞지 않는다. ‘14개 과제 모두 SOTA’도 원문의 전체 종합 성능 주장을 과장한다. v0의 문헌 수를 복원할 때 이런 요약을 그대로 옮기면 안 된다. [로컬 PDF](<../논문/06_SSL_Evaluation_Methodology/[2024_ICLR] Li_MERT_MusicSSL.pdf>)
- **Oliver et al.:** 로컬 PDF의 초록과 평가 문제 논의를 확인했다. 감독 기준선과 라벨·검증 조건의 중요성을 설명하는 근거로 사용한다. 특정 문제를 해당 논문이 열거하지 않았다는 사실만으로 우리 연구가 새로운 누수 유형을 최초 발견했다고 결론낼 수 없다. 로컬 파일은 2019년 arXiv 개정본이므로 최종 인용 시 게재본과 버전을 맞춘다. [로컬 PDF](<../논문/06_SSL_Evaluation_Methodology/[2018_NeurIPS] Oliver_RealisticSSLEvaluation.pdf>)

나머지 v0 참고문헌 전체를 이번 분석에서 원문 재검증한 것은 아니다. 논문별 역할과 뒷받침할 문장을 먼저 정하고, 실제 복원할 문헌의 해당 절·표를 집필하면서 대조한다. ‘32편에서 없었다 → 분야 최초’라는 기존 계획의 논리는 채택하지 않는다.

## 5. 국문 v2의 논리 흐름

| 순서 | 독자가 이해해야 할 것 | 사용할 자료와 작성 기준 |
|---|---|---|
| 1. 서론 | 왜 주법 분류에서 라벨 제약과 악기종 변화가 중요한가? | 주법 인식의 음악적 배경, 두 접근을 비교할 동기, 핵심 질문 하나. 보편적 모델 우열을 전제하지 않음 |
| 2. 관련 연구 | 특징 기반·사전학습 기반 접근과 우리의 설정은 어떻게 이어지는가? | v0 문헌 중 직접 관련된 자료를 원문 대조 후 복원. 평가 조건 차이를 설명 |
| 3. 데이터와 방법 | 무엇을 어떤 조건에서 비교했는가? | 5개 주법과 분포, 악기종 보류, 관측 라벨 분할, 고정 표현/특징과 분류기, 학습·선택, 지표 순서 |
| 4. 결과 | 라벨 예산·악기종·주법별로 무엇이 관찰됐는가? | 평균 곡선 → 악기종·주법별 차이 → 자기학습 대조 → 재표집 민감도. 수치와 관찰을 우선 |
| 5. 논의와 한계 | 이 결과가 모델 선택과 음악적 해석에 주는 의미는 무엇인가? | 평균 우열의 조건 의존성, 특정 주법의 혼동, 자기학습의 제한적 효과, 관찰만으로 설명하지 못한 원인 |
| 6. 결론·재현성 | 무엇을 확인했고 어디까지 적용할 수 있는가? | 연구 질문에 직접 답하고 자료 재계산 범위를 기술. 새로운 주장이나 미검증 실험을 추가하지 않음 |

음악적 설명은 **주법의 정의 → 실제 관찰한 오류 → 가능한 해석 → 현재 확인하지 못한 원인**의 순서로 쓴다. 예를 들어 ordinario와 sul ponticello의 혼동을 제시하고, 연주 방식과 음색 차이를 문헌으로 설명할 수 있다. 그 다음 ‘해당 단서를 모델이 충분히 이용하지 못했을 가능성’을 논의하되, 실제 사용 단서를 검증한 결과처럼 쓰지 않는다.

v1의 기존 그림 3개는 평균 곡선·오류·불확실성을 설명하므로 유지할 근거가 있다. 추가 그림은 학습/검증/테스트 흐름도 1개를 우선한다. 악기종·주법별 수치는 표로 보강하고, 표보다 그림이 분명할 때만 도표로 바꾼다. 그림 개수와 페이지 수는 원고를 쓰기 전에 목표로 고정하지 않는다.

## 6. 집필 목표와 완료 기준

작업 순서는 **국문 v2 본문 → 표·그림·인용 대조 → 국문 DOCX·PDF**로 고정한다. 본문은 `paper/manuscripts/v2/`에 작성한다. 영어 번역과 후속 연구 설계는 국문 전체 원고 검토 이후에 진행한다.

완료 기준은 다음 다섯 가지다.

1. 초록·서론·결론이 같은 핵심 질문에 답하며, 단락마다 다음 절이 필요한 이유가 이어진다.
2. 모든 결과 수치가 현재 CSV·예측에서 추적되고, 데이터 수·분모·평균 방식·비교 조건이 명확하다.
3. 직접 관찰, 문헌에 근거한 설명, 가능한 해석을 문장에서 구별한다.
4. v0의 복원 가능한 배경과 방법을 충분히 설명하고, 근거가 부족한 결론은 새로운 수사로 되살리지 않는다.
5. 새로운 학습을 추가하지 않고 현재 자료로 완성한 원고의 기여와 한계를 정확히 평가할 수 있다.

현재 자료는 국문 전체 원고를 작성할 기반을 제공한다. 학술지 연구 논문으로 충분한 독립 기여가 있는지는 원고 완성 후 별도로 판단할 문제다. 이전에 제안한 여러 확장 실험이나 단어 수를 지금 집필의 선행 조건으로 삼을 필요는 없다.
