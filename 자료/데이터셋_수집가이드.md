# 현악기 주법(Playing Technique) 라벨 데이터셋 전체 조사 (HuggingFace/논문/GitHub/Kaggle/Zenodo)

OrchideaSOL(고립 단음) 외에, 실연주 또는 그에 가까운 현악기 주법 라벨 데이터를 전부 조사한 결과.
Kaggle에는 이 주제의 정제된 데이터셋이 없었고(개인 토이 프로젝트 수준만 존재), 진짜 자산은
학술 논문이 직접 공개한 데이터셋과 HuggingFace 호스팅 데이터셋에 몰려 있음.

## Tier 0 — 즉시 다운로드 + 우리 5클래스 중 3개 직접 포함 (최우선)

### Philharmonia Orchestra Sound Samples

- **내용**: 20개 악기, 13,679개 단음 샘플. **주법 변형 포함: tremolo, pizzicato, sul ponticello(=ponticello), trill, vibrato, staccato, sustain**
- **우리 클래스 겹침**: **5클래스 전부** (ordinario/pizzicato/tremolo/sul_ponticello/col_legno_battuto)
- **실제 파일 수 (2026-06-30 탐색 완료)**:
  - ordinario (arco-normal): 3,072개 — 바이올린 852, 비올라 709, 첼로 747, 더블베이스 764
  - pizzicato (pizz-normal): 105개 — 바이올린 49, 비올라 39, 더블베이스 15, 첼로 2
  - col_legno_battuto (arco-col-legno-battuto): 73개 — 바이올린 44, 더블베이스 10, 첼로 18, 비올라 1
  - tremolo (arco-tremolo): 57개 — 바이올린 42, 나머지 15
  - sul_ponticello (arco-sul-ponticello): 42개 — **바이올린 39, viola/cello/double bass 각 1**
- **파일 위치**: `data/philharmonia/Strings/{violin,viola,cello,double bass}/`
- **파일명 형식**: `{instrument}_{pitch}_{duration}_{dynamic}_{technique}.mp3`
- **포맷**: MP3 (OrchideaSOL은 WAV — 로드 시 librosa 자동 변환 가능)
- **주의사항**: sul_ponticello는 바이올린 편중 심함. col_legno는 `arco-col-legno-battuto`와 `arco-col-legno-tratto` 구분 필요 (battuto만 매핑).
- **규모**: 악기당 pp/p/f/ff 다이내믹 × 음역 전체 크로마틱 × 주법 변형
- **라이선스**: CC BY-SA 3.0 (상업/학술 모두 자유)
- **활용**: OrchideaSOL과 동일한 고립 단음 형식 — 도메인 교차 검증 테스트셋 또는 학습 데이터 보강에 사용 가능.

## Tier 1 — 즉시 사용 가능 + 우리 4클래스와 직접 겹침 (최우선)

### 1. Dalmazzo & Ramírez Bowing Gestures Dataset (UPF MTG, 2019)
- **내용**: 전문 바이올리니스트가 실제로 연주한 7개 보잉 기법(Détaché, Martelé, **Spiccato**, Ricochet, Sautillé, Staccato, Bariolage)의 오디오 + Myo 센서 모션 데이터.
- **실제 확인 결과 (2026-06-30)**: PMC 논문의 Data Availability가 가리키는 GitHub 저장소 (`Dazzid/DataToRepovizz`, `myo_to_repovizz` 브랜치)에는 **IMU 센서 CSV 데이터만 있고 오디오 파일 없음**. 후속 저장소 `Deep_Learning_Spectrogram_Gestures`도 동일 — IMU 데이터에서 파생된 mel-spectrogram만 있음. 저자의 모든 공개 레포(18개) 확인 완료, 오디오 없음.
- **현재 접근 방법**: 저자 직접 이메일 요청 필요 — David Dalmazzo (UPF MTG, david.dalmazzo@upf.edu)
- **수집 행동**: 이메일로 "오디오 데이터 공유 가능 여부" 문의. 응답 대기 중 Tier 4 진행.

## Tier 2 — 진짜 실연주 + 기법 라벨 있음, 단 어휘가 우리 4클래스와 다름 (정렬 작업 필요)

### 2. MOSA Dataset (Music mOtion with Semantic Annotation, 2024)
- **내용**: 23명의 전문 연주자(바이올린 15명) × 742개 공연, 570K개 음표 단위 주석.
- **실제 확인 결과 (2026-06-30)**: Zenodo 11393449 — 오디오 있으나 **접근 제한 (restricted)**. 로그인 후 요청 제출 필요. 라벨 스키마 확인 결과 articulation은 **legato, staccato** 위주로 우리 5클래스(pizzicato/tremolo/sul_ponticello/col_legno 등)와 직접 매핑 어려움. "바이올린·피아노 클래식 연구 목적" 제한 조건.
- **수집 행동**: 접근 요청은 가능하나 라벨 스키마 불일치로 우선순위 낮춤. 일반화 테스트 오디오 소스로만 활용 고려.

### 3. SyncViolinist Dataset (2024)
- **내용**: 3명의 전문 바이올리니스트, 61곡, 182.5분. arXiv 2412.08343.
- **실제 확인 결과 (2026-06-30)**: 라벨이 **보우 방향(up/down)과 핑거링**으로 우리가 원하는 기법 카테고리 아님. 데이터 공개 여부 불명확 — 논문에 저장소 링크 없음.
- **수집 행동**: 보류.

### 4. EEP — Ensemble Expressive Performance Dataset (UPF MTG)
- **실제 확인 결과 (2026-06-30)**: UPF 서버 전체 403/404 응답. repovizz2.upf.edu 도메인 불존재. 현재 접근 불가.
- **수집 행동**: UPF MTG 직접 이메일 문의 필요. 보류.

## Tier 4 — 비서구 활(弓) 현악기: 방법론이 거의 그대로 전이됨 + 문화 다양성 보너스

### 5. Erhu Playing Technique Dataset

두 버전이 존재하며 동일 데이터셋일 가능성이 높음:

| 버전 | 링크 | 접근 | 용량 |
|---|---|---|---|
| **Zenodo** (Peking Univ., 2020) | zenodo.org/records/4320991 | CC BY 4.0, 즉시 다운로드 | ErhuPT.zip 221.8MB |
| **HuggingFace** (ccmusic-database) | `load_dataset("ccmusic-database/erhu_playing_technique")` | 즉시 | — |

- **기법**: detache, diangong, harmonic, legato&slide&glissando, percussive, **pizzicato**, ricochet, staccato, **tremolo**, trill, vibrato (11기법)
- **우리 클래스 겹침**: pizzicato, tremolo 2개
- **활용**: "서구 찰현악기 학습 모델 → 동족 비서구 악기 제로샷 전이" 실험. ISMIR 문화 다양성 의제와 일치.
- **주의**: CCMusic Erhu와 Zenodo Erhu PT가 동일 데이터인지 라벨 스키마 비교 후 결정 필요.

### 6. CCOM-HuQin (Chinese Fiddle Multimodal Dataset)
- **내용**: 후친(胡琴) 계열 악기 멀티모달(오디오+영상), ISMIR/TISMIR 논문.
- **접근성**: 미확인. 필요 시 추가 조사.

## 반드시 읽어야 할 인접 연구

**VioPTT / MOSA-VPT (arXiv 2509.23759, 2025년 9월)** — 바이올린 주법 인식을 합성 데이터로 학습시켜 실연주(Bach10, RWC)에 일반화시키는, 우리가 하려는 것과 거의 동일한 방향의 매우 최근 논문. **우리 논문이 반드시 인용하고 차별점을 명시해야 하는 직접 경쟁 연구.**

차별점 후보:
- (a) 우리는 합성이 아니라 OrchideaSOL 실제 녹음 기반
- (b) ALM 환각 평가 + SHAP 해석가능성 축이 VioPTT에 없음
- (c) Self-training을 통한 라벨 효율성 분석도 VioPTT에 없음
